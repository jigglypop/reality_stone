# 리얼리티 스톤: 이질 LLM 리만 병합 이론 (Heterogeneous Merge)

## 1. 이질 LLM 리만 병합 이론의 핵심 결론

> **"서로 전혀 다른 LLM(예: LLaMA + Mistral)을 동일 리만 기하공간(M, g)에 매핑하면 자연스럽게 합체(Merge)된다."**

Reality_Stone 방식은 가중치를 합치는 것이 아니라, **기하학(Metric)을 공유시키는 구조**이기 때문입니다.

---

## 2. 유클리드 vs 리만: 이질 LLM 병합 가능성 이론 (Euclidean vs Riemannian)

-   **기존 Transformer (Euclidean)**:
    -   서로 다른 좌표계, Attention head 불일치, Layernorm 차이 등으로 인해 직접 결합 불가능.
-   **Reality_Stone (Riemannian)**:
    -   두 모델이 구조가 달라도 $x \rightarrow \log_g(x)$를 통해 **동일한 Metric $g$로 평탄화**되면, 같은 **Tangent space($T_p M$)**를 공유하게 됩니다.
    -   Tangent space는 유클리드 공간이므로 선형 결합이 가능합니다.

$$
f_{merge}(x)=\exp_g((A_A+A_B)\log_g(x))
$$

이것이 **두 LLM의 합체**입니다.

---

## 3. 리만 공간에서의 LLM 합체 방식 이론

### ① 탱전트 공간 병합 이론 (Tangent-space Merge, 가장 안정적)
$$
A_{merge} = A_A + A_B
$$
-   두 모델의 기능이 평균처럼 합쳐짐. 정합성이 높고 붕괴가 없음.

### ② 주곡률 정렬 기반 합성 이론 (Principal-Curvature Alignment)
각 모델의 고유 곡률 방향(eigen-curvature)을 추출하여 결합:
$$
\Lambda_{merge} = \text{diag}(\lambda_i + \mu_i)
$$
-   **능력치 자체가 합쳐진 행동** (Reasoning A + Reasoning B).

### ③ 교대 기하학 구성 이론 (Hybrid Manifold)
레이어별로 기하적 구조를 번갈아 사용 (Layer 1: LLaMA, Layer 2: Mistral ...).
-   완전히 새로운 **하이브리드 LLM** 탄생.

---

## 4. 이론적 성능 및 기대 효과

-   **품질 보존**: Tangent-space에서 정규화 후 합치므로, 기존 Merge 기법(MergeKit 등)에서 발생하는 Layernorm 충돌이나 값 폭주 문제가 없습니다.
-   **실제 기대 성능**:
    -   예: Mistral 7B + LLaMA 8B Merge
    -   수학(Mistral) + 지식(LLaMA) 결합
    -   Intrinsic rank 압축으로 모델 크기/속도는 4~8B 수준 유지
    -   **결과: "7B+8B = 15B급 품질, 하지만 4B급 속도"**

---

## 5. 이질 LLM 리만 병합 이론 요약

이질적인 두 LLM을 합치는 것은 가중치 결합이 아니라, **두 모델의 잠재 다양체(Latent Manifold)를 하나의 Metric으로 재해석한 뒤, 그 Tangent-space에서 매핑을 합성하는 것**입니다.
