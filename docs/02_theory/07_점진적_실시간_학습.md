# 15장. 추가 학습 및 모델 병합 (Incremental Learning & Model Merging)

## 1. 기하학적 모델 병합 (Geometric Model Merging)

### 개념
두 개의 서로 다른 모델(예: 법률 모델 $A$와 의학 모델 $B$)을 합치고 싶을 때, 기존 방식(가중치 평균)은 두 모델의 지식을 모두 망가뜨립니다.
Reality Stone은 두 모델을 **서로 다른 부분 공간(Subspace)**을 점유하는 다양체로 보고, 이들을 **합집합(Union)**합니다.

### 수학적 원리: 곱 다양체 (Product Manifold)
두 모델의 파라미터 공간을 리만 곱 다양체로 정의합니다.
$$ M_{total} = M_A \times M_B $$

병합된 가중치 $W_{merged}$는 단순 덧셈이 아니라, **블록 대각 행렬(Block Diagonal Matrix)** 형태의 메트릭 텐서 결합입니다.

$$ G_{merged} = \begin{pmatrix} G_A & 0 \\ 0 & G_B \end{pmatrix} $$

### 구현: 메트릭 인터폴레이션 (Metric Interpolation)
만약 두 모델이 같은 구조를 공유한다면, 측지선 보간(Geodesic Interpolation)을 사용합니다.
$$ W_{merged} = \text{Exp}_{W_A}(t \cdot \text{Log}_{W_A}(W_B)) $$
이것은 가중치 공간에서 두 지식 사이의 "최단 경로" 상에 있는 점을 찾아내어, 두 능력을 가장 조화롭게 섞는 지점입니다.

# 실시간 학습 (Real-time / Online Learning)

## 1. 문제점
기존 모델은 새로운 정보를 배우려면 전체 역전파(Backpropagation)가 필요하며, 이는 느리고 비용이 많이 듭니다.

## 2. 리만 해법: 국소 메트릭 업데이트 (Local Metric Update)
전체 가중치 $W$를 고정하고, 오직 **작은 메트릭 텐서 $G$ (64x64 크기)**만 실시간으로 업데이트합니다.

### 알고리즘
새로운 데이터 $x_{new}$가 들어오면:
1. $x_{new}$를 현재 기저 벡터로 투영합니다.
2. 투영된 공간에서의 에러(Loss)를 계산합니다.
3. **메트릭 텐서 $G$만** 경사 하강법으로 업데이트합니다.
   $$ G_{t+1} = G_t - \eta \nabla_G \mathcal{L} $$

### 효과
- **즉시성**: $G$는 매우 작으므로 밀리초(ms) 단위로 업데이트 가능합니다.
- **안전성**: 거대한 지식 베이스($W$)는 건드리지 않으므로 기존 지식이 파괴되지 않습니다.
- **적응성**: 모델이 실시간 대화 맥락이나 사용자의 성향에 맞춰 즉각적으로 공간을 "구부립니다".

이것이 바로 Reality Stone이 제안하는 **"살아있는 AI"**의 핵심입니다.
