# 8장 지오데식 압축 구현 로드맵 v2 (상세 문서)

---

### 0. 범위와 최종 목표

- **최종 목표**
  - 기존 Transformer(예: Mistral, Qwen, LLaMA)의 한 레이어를 **RS‑ULF 레이어**로 치환하고,
  - 그 위에 **지오데식 기반 압축(폴딩 + KV 스플라인)** 을 단계적으로 얹어서,
  - 다음을 동시에 만족하는 엔진을 구현하는 것:
    - 표현력: 원본 Transformer와 **동급 또는 ε‑손실 수준**.
    - 시간 복잡도: **레이어당 \(O(n^2 d) \to O(n d)\)**.
    - 모델/캐시 메모리: **최소 10× 이상 절감**.

- **3단계 전략**
  1. **1단계**: 압축 없이, 기존 레이어를 **무압축 RS‑ULF 래핑**으로 완전히 동치에 가깝게 만드는 것.
  2. **2단계**: RS‑ULF 위에 **폴딩(SVD) + 글로벌 베이시스 압축**을 옵션으로 얹는 것.
  3. **3단계**: KV 캐시를 **지오데식 스플라인**으로 압축하는 별도 모듈을 붙이는 것.

- **성공 기준(요약)**
  - 레이어 단위: `TransformerLayer(x)` vs `RSULFLayer(x)` **코사인 유사도 ≥ 0.98**.
  - 작은 모델 기준 PPL 열화 ≤ **5% 이내** (1단계 끝).
  - 폴딩/압축 후에도 레이어 정합성 테스트(코사인, L2, 폴드 정확도) 통과.

## 1단계: 무압축 RS‑ULF 래핑 완성

### 1.1 설계 개요

- **아이디어**
  - **가중치는 그대로 두고**, 기존 레이어가 수행하던 계산을
    - 메트릭 \(g\),
    - 포텐셜 \(\Phi\),
    - 지오데식 업데이트 \(x' = \exp_x(\cdot)\),
    - 그래프 디퓨전 \(Lx\),
    - DP 메모리 \(V_t\)
    로 재조합한 **RS‑ULF 레이어**를 만든다.
- **여기서는 “압축” 없음**:
  - SVD, folding, global basis 없이 **원본 \(W_Q, W_K, W_1, W_2\)** 를 그대로 사용.
  - 목표는 “정합성”과 “동역학 구조” 확보.

### 1.2 서브모듈 정의

#### 1.2.1 `RiemannianMetric` (Diagonal 버전)

- **입력**
  - `WQ: (d_q, d)`
  - `WK: (d_k, d)`
- **출력**
  - `g_diag: (d,)` – 대각 메트릭
  - `g_inv_diag: (d,)` – 대각 역메트릭

- **정의**

  \[
  G_{\text{raw}} = W_Q^\top W_K \in \mathbb{R}^{d \times d}
  \]

  \[
  g_{ii} = \max\big(|G_{\text{raw}, ii}|,\ \epsilon\big),\quad \epsilon \approx 10^{-6}
  \]

  \[
  (g^{-1})_{ii} = 1 / g_{ii}
  \]

- **역할**
  - 리만 내적 \(\langle u, v\rangle_g = \sum_i g_{ii} u_i v_i\) 계산.
  - Riemannian gradient \(\nabla_g \Phi = g^{-1} \nabla\Phi\) 계산에 사용.

- **체크포인트**
  - 모든 \(g_{ii} > 0\).
  - `g_diag.min() >= eps`, `g_diag.max()`가 너무 크지 않도록 클램핑.

#### 1.2.2 `PotentialFunction` (FFN 기반 포텐셜)

- **입력**
  - `W1: (d_ff, d)`, `W2: (d, d_ff)` (+ `W_up` 등은 연장선)
  - hidden state `x: (B, L, d)`
- **정의**

  - FFN:
    \[
    f(x) = W_2\, \sigma(W_1 x) \quad (\text{또는 SwiGLU/GEGLU 변형})
    \]

  - 포텐셜:
    \[
    \Phi(x) = \frac12 \|f(x)\|^2
    \]

  - Gradient(autograd):
    - 코드 레벨에서 `phi.sum().backward()`로 `∇Φ(x)` 확보.

- **역할**
  - FFN을 **에너지/힘**로 재해석하는 핵심 모듈.
  - RS‑ULF에서 `-∇_g Φ` 항을 구성.

- **체크포인트**
  - `Φ(x)` shape: `(B, L)` (스칼라 포텐셜).
  - `∇Φ(x)` shape: `(B, L, d)`.
  - `cos(f(x), ∇Φ(x))` 평균 ≥ 0.9 정도를 목표.

#### 1.2.3 `GraphLaplacian` (시퀀스용 단순 그래프)

- **입력**
  - `seq_len: L`
  - `window_size: w` (로컬 어텐션 윈도우; 예: 8, 16 등)
- **정의**

  - 인접행렬:

    \[
    A_{ij} =
    \begin{cases}
      1 / (1 + |i-j|) & \text{if } 0 < i-j \le w \\
      0 & \text{otherwise}
    \end{cases}
    \]

  - 차수/라플라시안:

    \[
    D_{ii} = \sum_j A_{ij}, \quad L = D - A
    \]

- **역할**
  - `Lx`가 **로컬 causal diffusion**을 의미하도록 설계.
  - 주로 “어텐션의 로컬 정보 공유 역할” 대체.

- **체크포인트**
  - \(L\,\mathbf{1} = 0\) (상수 벡터는 커널).
  - 작은 예제에서 디퓨전 반복 시 에너지 감소 확인.

#### 1.2.4 `BellmanMemory`

- **정의**

  \[
  V_t = \gamma V_{t-1} + \Phi(x_t), \quad 0 < \gamma < 1
  \]

- **역할**
  - long‑range 정보를 **스칼라(또는 저차원)** 로 누적.
  - Attention이 하던 “아주 먼 과거 토큰에 대한 영향” 일부를 대신함.

- **체크포인트**
  - `V`가 overflow/underflow 없이 안정.
  - 일정한 `Φ`에 대해 이론적 극한값 \(\Phi / (1-\gamma)\) 근사.

### 1.3 `RSULFLayer` v1 정의

- **입력**
  - `x: (B, L, d)` – 현재 레이어 입력(hidden)
  - `V_prev: (B, L)` – 이전 메모리(없으면 `None`)
- **출력**
  - `x_next: (B, L, d)` – 업데이트 된 hidden
  - `V_next: (B, L)` – 업데이트 된 메모리

- **업데이트 식(1단계 버전)**

  1. Metric, inverse metric 계산:
     \[
     g, g^{-1} \leftarrow \text{RiemannianMetric}(W_Q, W_K)
     \]

  2. FFN 포텐셜/그라디언트:
     \[
     \Phi(x),\ \nabla \Phi(x) \leftarrow \text{PotentialFunction}(x)
     \]

  3. Riemannian gradient:
     \[
     \nabla_g \Phi(x) = g^{-1} \nabla \Phi(x)
     \]

  4. 기초 diffusion(라플라시안 근사):
     \[
     \Delta_g x \approx x - \bar x \quad (\bar x: \text{sequence mean})
     \]

  5. 그래프 디퓨전:
     \[
     Lx \leftarrow \text{GraphLaplacian}(x)
     \]

  6. 메모리 업데이트:
     \[
     V_t = \begin{cases}
       \Phi(x) & V_{t-1} = \text{None}\\[4pt]
       \gamma V_{t-1} + \Phi(x) & \text{otherwise}
     \end{cases}
     \]

  7. 통합 업데이트 벡터:
     \[
     v = -\eta \nabla_g \Phi(x) + \alpha (x - \bar x) + \beta Lx + \gamma V_t
     \]

  8. 지오데식 1차 근사:
     \[
     x_{t+1} = x + v
     \]

- **하이퍼파라미터 가이드(1단계)**
  - \(\eta \in [0.005, 0.05]\)
  - \(\alpha \in [0.01, 0.05]\)
  - \(\beta \in [0.0, 0.02]\)
  - \(\gamma \in [0.95, 0.995]\)

### 1.4 1단계 테스트 플랜

- **Test A – Metric 정합성**
  - 여러 샘플 \(x_i, x_j\)에 대해:
    \[
    (W_Q x_i)^\top (W_K x_j) \approx x_i^\top G_{\text{raw}} x_j
    \]
  - 평균 L2 오차가 작으면 OK (절대 일치까지는 요구 X, 대략적 정합성 확인용).

- **Test B – FFN vs ∇Φ**
  - 여러 \(x\)에 대해:
    - Transformer FFN 출력 `f(x)` vs `∇Φ(x)` 코사인 유사도 평균 ≥ 0.9 목표.

- **Test C – 레이어 출력 정합성**
  - 같은 입력 `x0`에 대해:
    - 원본 레이어 출력 `T(x0)`,
    - RS‑ULF 레이어 `R(x0, V=None)` 비교.
  - 코사인 유사도 ≥ 0.98,
  - 정규화된 L2 오차( `||T-R|| / ||T||` )가 작은지 확인.

- **Test D – 시퀀스 안정성**
  - 작은 모델/작은 데이터셋으로:
    - 여러 스텝 반복 적용 시, 폭주 없이 loss 감소/수렴 패턴 확인.

## 2단계: 폴딩(Folding) + 글로벌 베이시스 압축

### 2.1 목표와 제약

- **목표**
  - 1단계 RS‑ULF 레이어의 **표현력은 유지**하면서,
  - 파라미터 수/연산량을 **대폭 줄이는 옵션**을 붙이는 것.
- **전략**
  1. **단일 레이어 SVD 폴딩(per‑layer)** 을 먼저 도입.
  2. 그 다음, 여러 레이어의 Q/K를 합친 **global basis** 설계로 확장.

### 2.2 Per‑Layer SVD 폴딩

#### 2.2.1 메트릭 폴딩

- **입력**
  - 레이어별 메트릭 후보:
    \[
    G^{(l)}_{\text{raw}} = W_Q^{(l)\top} W_K^{(l)} \in \mathbb{R}^{d \times d}
    \]
- **폴딩**
  - SVD:
    \[
    G^{(l)}_{\text{raw}} \approx U^{(l)}_r \Sigma^{(l)}_r V^{(l)\top}_r,\quad r \ll d
    \]
  - 압축 저장:
    - `U_r: (d, r)`, `Σ_r: (r,)`, `V_r: (d, r)` 조합 또는
    - metric core `G_core^{(l)} ∈ R^{r×r}`로 변환해 두고, 실제 metric 계산 시 low‑rank 구조 사용.

- **정합성 지표**
  - 폴드 정확도:
    \[
    \text{Acc}_l = \frac{\sum_{i=1}^{r} \sigma_i^{(l)2}}{\sum_{i=1}^{d} \sigma_i^{(l)2}} \ge 0.9
    \]
  - 재구성 오차:
    \[
    \epsilon_{\text{recon}}^{(l)} = \frac{\|G^{(l)} - U^{(l)}_r \Sigma^{(l)}_r V^{(l)\top}_r\|_F}{\|G^{(l)}\|_F}
    \]

#### 2.2.2 FFN 폴딩(단순 SVD 버전)

- **1차 버전**
  - \(W_1, W_2\)에 대해 각각 rank‑r 근사 수행.
  - `W1 ≈ U1_r S1_r V1_r^T`, `W2 ≈ U2_r S2_r V2_r^T`.
- **역할**
  - 파라미터/연산량 줄이기 (FFN 부분만 따로 압축).

- **2차 버전(포텐셜 증류는 2단계 후반)**  
  - FFN 전체를 Neural Potential로 다시 학습하는 것은 **추가 연구 단계**로 남기고,  
    2단계 전반은 순수 SVD 압축 + 정합성 테스트만으로 제한.

### 2.3 Global Basis 설계 (여러 레이어 공유)

#### 2.3.1 Global Metric Basis

- **입력**
  - 모든 레이어의 Q/K:
    \[
    M_Q = \begin{bmatrix}W_Q^{(1)}\\\vdots\\W_Q^{(L)}\end{bmatrix},\quad
    M_K = \begin{bmatrix}W_K^{(1)}\\\vdots\\W_K^{(L)}\end{bmatrix}
    \]

- **Global SVD**
  \[
  G_{\text{all}} = M_Q^\top M_K \approx U_\* \Sigma_\* V_\*^\top
  \]

- **레이어별 코어**
  \[
  g^{(l)}_{\text{core}} = U_\*^\top G^{(l)}_{\text{raw}} U_\* \in \mathbb{R}^{r \times r}
  \]

- **장점**
  - Global `U_\*`를 **한 번만 저장**하고, 레이어별로 작은 `g_core^{(l)}`만 보관 → 모델 전체 압축.

#### 2.3.2 Curvature Compensation

- **버려진 특이값 집합**
  \[
  S_{\text{res}}^{(l)} = \{\sigma_{r+1}^{(l)}, \dots\}
  \]

- **레벨별 곡률 스칼라**
  \[
  \kappa^{(l)} = \Big(\sum_{i>r} (\sigma_i^{(l)})^2\Big)^{1/2}
  \]

- **업데이트에 반영(옵션)**
  - 예: 업데이트 벡터에 2차 보정항 추가:
    \[
    \delta^{(l)} = -\tfrac12 \kappa^{(l)} \|v\|^2 x
    \]
  - 초기 구현에서는 **로그만 찍고 분석**, 실제 동역학에 반영은 후순위.

### 2.4 2단계 테스트 플랜

- **폴딩 내부 테스트**
  - 각 레이어에서:
    - 폴드 정확도 ≥ 0.9,
    - 조건수 허용 범위, 재구성 오차 적정 수준.

- **레이어 정합성 재테스트**
  - 폴딩 이후:
    - `T(x)` vs `RSULFLayer_folded(x)` 코사인 유사도 ≥ 0.95 이상 유지.
  - FFN vs ∇Φ도 동일 지표로 확인 (필요 시 rank 조정).

- **모델 레벨 스팟 체크**
  - 작은 데이터셋에서 PPL, 간단 QA 등으로 원본 대비 열화 측정.
  - 압축률(파라미터 수, 메모리) vs 정확도 trade‑off 테이블 정리.

## 3단계: 지오데식 스플라인 기반 KV 압축 (별도 모듈)

### 3.1 역할과 분리 원칙

- **역할**
  - Attention을 모두 제거하거나 약화한 RS‑ULF 구조에서,
  - 시퀀스상의 “시간 축 궤적”을 **제어점만 저장**하고 나머지는 **지오데식 스플라인으로 복원**.
- **분리 원칙**
  - `RSULFLayer`는 순수 연산자:
    - 입력 hidden → 한 스텝 geodesic 업데이트.
  - KV 스플라인 압축은:
    - `KVGeodesicSplineCache` 같은 **독립 모듈**로 구현.
    - RS‑ULF 레이어와는 “입력/출력 hidden”을 통해서만 연결.

### 3.2 제어점 선택(샘플링) 이론

- **곡률/가속도 기반**
  - 시간 \(t\)에서 상태 \(x_t\), 속도 \(v_t\), 가속도 \(a_t\)라 할 때:
    - 곡률 크기 \(\kappa_t \approx \|a_t\|\).
  - 임계값 \(\theta\) 설정:
    \[
    \text{if } \|a_t\| > \theta \Rightarrow t \text{를 제어점으로 추가}
    \]
- **실제 저장 항목**
  - 각 control point마다 `(t_k, x_{t_k}, v_{t_k})` 저장.
  - KV 캐시 메모리:
    \[
    \text{O}(\rho N D),\quad \rho \ll 1
    \]

### 3.3 스플라인 복원식(근사)

- **구간 \([t_k, t_{k+1}]\)에서**
  - 1차/2차 근사:
    \[
    x(t) \approx \exp_{x_{t_k}}\Big( (t - t_k) v_{t_k} + \tfrac12 (t - t_k)^2 F(x_{t_k}) \Big)
    \]
  - 여기서 \(F(x_{t_k}) \approx -\nabla_g \Phi(x_{t_k})\) 또는 RS‑ULF 업데이트 항 일부로 근사.

- **실제 구현**
  - 간단하게는:
    - 유클리드 근사: \(x(t) \approx x_{t_k} + (t-t_k) v_{t_k}\) 부터 시작,
    - 곡률/힘 보정은 후속 연구로 분리.

### 3.4 인터페이스 스케치

- **`KVGeodesicSplineCache`**
  - `push(t, x_t, v_t)`: 곡률 검사를 통해 제어점 여부 판단 후 저장.
  - `reconstruct(t_query) -> x_hat`: 필요한 시점의 hidden 복원.
- **RS‑ULF 연동**
  - 디코더/추론 루프에서:
    - 새 토큰 생성 시:
      - `cache.push(t, x_t, v_t)`
    - 반복/드롭아웃된 토큰 참조 시:
      - `x_ref = cache.reconstruct(t_ref)`로 상태 복원 후 사용.

### 3.5 3단계 테스트 플랜

- **정합성 테스트**
  - 스플라인 없이 RS‑ULF를 full trajectory로 돌린 결과와,
  - 스플라인 기반 캐시로 복원한 결과의 hidden 차이(L2, 코사인)를 측정.
- **압축률/속도 테스트**
  - 제어점 비율 \(\rho\)를 변화시키면서:
    - 메모리 사용량,
    - 복원 오차,
    - 속도 향상 측정.
