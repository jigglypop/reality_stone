# 리만 라그랑지안 디퓨전 (Riemannian Lagrangian Diffusion)

## 개요

Reality Stone의 핵심 연구 방향 중 하나인 **리만 라그랑지안 디퓨전**은 신경망 학습을 **물리학적 역학 시스템**으로 재해석합니다. 일반적인 유클리드 공간이 아닌 **곡률이 있는 다양체(Riemannian Manifold)** 위에서 에너지 기반 역학을 통해 표현을 학습합니다.

### 핵심 아이디어

1. **상태 공간 = 리만 다양체**: 신경망의 은닉 상태가 푸앵카레 공(Poincaré Ball) 같은 쌍곡 공간에 존재합니다.
2. **학습 = 에너지 최소화**: 그래디언트 하강이 아니라 **라그랑지안 역학**에 따른 자연스러운 흐름입니다.
3. **디퓨전 = 시간 진화**: 초기 상태에서 시작하여 측지선(Geodesic)을 따라 에너지가 낮은 상태로 이동합니다.

## 1. 수학적 기초

### 1.1 상태, 다양체, 메트릭

- **상태**: $h \in \mathcal{M}$, 여기서 $\mathcal{M}$은 리만 다양체 (예: Poincaré Ball)
- **메트릭 텐서**: $g_{ij}(h)$ - 곡률을 정의하는 메트릭
  - Poincaré Ball: $g_{ij} = \frac{4}{(1-c\|h\|^2)^2} \delta_{ij}$
  - Diagonal Metric: $g_{ij} = w_i(h) \delta_{ij}$ (학습 가능)

- **접공간 매개변수화**:
  - $z \in \mathbb{R}^d$ (유클리드 공간)
  - $h = \text{Exp}_0^c(z)$ (지수 맵으로 다양체로 사상)

### 1.2 에너지와 라그랑지안

**운동 에너지 (Kinetic Energy)**:
$$T(\dot{h}) = \frac{1}{2} g_{ij}(h) \dot{h}^i \dot{h}^j$$

**퍼텐셜 에너지 (Potential Energy)**:
- **벨만 잠재 에너지** (Bellman Potential):
  $$V_{\text{Bell}}(h_t, h_{t+1}) = \left( V(h_t) - (R_t + \gamma V(h_{t+1})) \right)^2$$
  
- **기하학적 퍼텐셜** (Geometric Potential):
  $$V_{\text{geom}}(h; \mu) = \frac{1}{2} d_c(h, \mu)^2$$
  여기서 $\mu$는 목표 프로토타입, $d_c$는 리만 거리

**라그랑지안**:
$$\mathcal{L}(h, \dot{h}) = T(\dot{h}) - V(h)$$

## 2. 디퓨전 역학 (Diffusion Dynamics)

### 2.1 이산 시간 업데이트

**Euler 스텝 (유클리드 근사)**:
$$h_{t+1} = h_t + \dot{h}_t \cdot dt$$

**리만 업데이트 (측지선 흐름)**:
$$h_{t+1} = \text{Exp}_{h_t}(v_t \cdot dt)$$

여기서 $v_t$는 접공간의 속도 벡터:
$$v_t = (1 - \alpha)(f_t - h_t)$$

- $f_t = \tanh(h_t W)$: 목표 흐름 (잠재 에너지 그래디언트 방향)
- $\alpha \in [0, 1]$: 감쇠 계수 (에너지 보존 vs 감쇠 조절)

### 2.2 다양체 제약 조건

업데이트 후 상태가 다양체를 벗어나지 않도록 **Retraction** 적용:
$$h_{t+1} = \text{Proj}_{\mathcal{M}}(h_{t+1}^{\text{raw}})$$

Poincaré Ball의 경우:
$$\text{Proj}(h) = \begin{cases}
h & \text{if } \|h\| < 1 - \epsilon \\
\frac{1 - \epsilon}{\|h\|} h & \text{otherwise}
\end{cases}$$

## 3. Reality Stone 구현

### 3.1 아키텍처 구조

```
Python (PyTorch)
    ↓
   [행렬 곱 h @ W - GPU/cuBLAS]
    ↓
   [Rust 바인딩 - Zero-Copy]
    ↓
   [CUDA 커널 - Riemannian Step]
    ↓
   [다시 PyTorch로 - Autograd 그래프]
```

### 3.2 구현 파일

**Rust 코어**:
- `src/layers/diffusion.rs`: 리만 디퓨전 로직
- `src/layers/metric.rs`: 메트릭 텐서 (Diagonal, Poincaré, Lorentz, Klein)
- `src/layers/geodesic.rs`: 지수/로그 맵
- `src/layers/bellman_lagrangian.rs`: 벨만-라그랑지안 에너지

**CUDA 커널**:
- `src/layers/cuda/diffusion.cu`: GPU에서 리만 스텝 수행

**Python 바인딩**:
- `src/bindings/diffusion.rs`: PyTorch 텐서 포인터를 받아 CUDA 호출

**실험 코드**:
- `experiments/benchmark_mnist_diffusion.py`: MNIST 디퓨전 실험

### 3.3 사용 예시

```python
import reality_stone as rs

# 1. Rust 엔진 초기화
engine = rs.PyRiemannianDiffusion(
    dim=2048,      # 은닉 차원
    alpha=0.9,     # 감쇠 계수
    dt=0.1         # 시간 간격
)

# 2. 디퓨전 스텝 (GPU Zero-Copy)
class RiemannianStep(torch.autograd.Function):
    @staticmethod
    def forward(ctx, h, flow, engine):
        h_next = torch.empty_like(h)
        engine.step_cuda(
            h.data_ptr(),
            flow.data_ptr(),
            h_next.data_ptr(),
            batch_size, dim
        )
        return h_next
    
    @staticmethod
    def backward(ctx, grad_output):
        # 유클리드 근사 그래디언트
        alpha = 0.9
        return grad_output * alpha, grad_output * (1-alpha), None

# 3. 학습 루프
for t in range(T):
    flow = torch.tanh(h @ W)  # PyTorch (GPU)
    h = RiemannianStep.apply(h, flow, engine)  # Rust+CUDA
```

## 4. 실험 결과

### 4.1 MNIST 분류 실험

**설정**:
- Hidden Dim: 2048
- Time Steps: 5
- Alpha (감쇠): 0.9
- Epochs: 5
- Batch Size: 256

**성능**:
- **정확도**: 97.18% (Best)
- **학습 시간**: ~8-9초/에폭 (GPU)
- **속도 향상**: CPU 복사 버전 대비 **10배 빠름**

**기존 대비 개선**:
| 구현 방식 | 에폭당 시간 | 정확도 |
|-----------|-------------|--------|
| CPU 복사 (Numpy) | ~85초 | - |
| Rust+CUDA Zero-Copy | ~9초 | 97.18% |

### 4.2 핵심 성과

1. **Zero-Copy GPU 가속**: PyTorch 텐서를 CPU로 복사하지 않고 직접 CUDA 커널에 전달
2. **리만 기하학 적용**: 다양체 제약 조건 하에서 학습이 안정적으로 수행됨
3. **Autograd 통합**: Rust-CUDA 커널이 PyTorch의 자동 미분 그래프와 완벽히 통합

## 5. 이론적 배경

### 5.1 벨만-라그랑지안 프레임워크

**벨만 방정식** (강화학습):
$$V(h_t) = R_t + \gamma V(h_{t+1})$$

**라그랑지안 역학** (물리학):
$$\frac{d}{dt}\frac{\partial \mathcal{L}}{\partial \dot{h}} - \frac{\partial \mathcal{L}}{\partial h} = 0$$

**통합**:
- 벨만 에러를 퍼텐셜 에너지로 해석
- 상태 업데이트를 라그랑지안 방정식의 해로 해석

### 5.2 기하학적 해석

**측지선 흐름**:
- 유클리드 공간: 직선
- 리만 다양체: 곡선 (측지선)
- 에너지 최소화 경로 = 측지선

**곡률의 의미**:
- **양의 곡률** (구면): 상태가 모이는 경향
- **음의 곡률** (쌍곡): 상태가 퍼지는 경향
- **계층 구조 학습**: 쌍곡 공간이 자연스럽게 계층 구조를 표현

## 6. 확장 가능성

### 6.1 응용 분야

1. **뇌 신경 역학 모델링**:
   - 뇌 상태를 리만 다양체로 표현
   - RDM(Representational Dissimilarity Matrix)를 리만 거리로 계산

2. **강화학습**:
   - 정책(Policy)을 다양체 위의 분포로 표현
   - 자연스러운 정책 그래디언트 (Natural Policy Gradient)

3. **생성 모델**:
   - 잠재 공간(Latent Space)을 리만 다양체로 설정
   - 측지선을 따라 보간(Interpolation)

4. **시계열 예측**:
   - 상태 천이를 리만 역학으로 모델링
   - 물리 법칙(에너지 보존)을 자연스럽게 반영

### 6.2 향후 연구 방향

1. **적응형 메트릭 학습**:
   - 메트릭 텐서 $g_{ij}$를 데이터 기반으로 학습
   - 작업(Task)에 최적화된 기하 구조 발견

2. **다중 다양체 융합**:
   - Poincaré + Lorentz + Klein 하이브리드
   - 각 다양체의 장점을 결합

3. **변분 리만 디퓨전**:
   - 확률적 디퓨전 프로세스
   - 불확실성(Uncertainty) 정량화

4. **대규모 모델 적용**:
   - Transformer 아키텍처에 리만 레이어 통합
   - 언어 모델, 비전 트랜스포머 확장

```python

engine = rs.PyRiemannianDiffusion(dim, alpha, dt)

# CUDA 스텝 (Zero-Copy)
engine.step_cuda(h_ptr, flow_ptr, out_ptr, batch_size, dim)

```

## 8. 결론

**리만 라그랑지안 디퓨전**은 Reality Stone 프로젝트의 핵심 기술로서, 신경망 학습을 **물리 법칙에 기반한 역학 시스템**으로 재해석합니다. 이를 통해:

1. **기하학적 귀납 편향** (Geometric Inductive Bias): 계층 구조, 대칭성 등을 자연스럽게 학습
2. **물리 기반 최적화**: 에너지 보존, 안정성 등 물리 법칙의 이점
3. **고성능 구현**: Rust+CUDA로 실용적인 속도 달성

이 프레임워크는 MNIST를 넘어 **뇌 모델링**, **강화학습**, **생성 모델** 등 다양한 분야에 적용 가능하며, Reality Stone을 **단순한 라이브러리**가 아닌 **새로운 학습 패러다임의 플랫폼**으로 발전시킵니다.
