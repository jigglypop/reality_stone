# 계층적 의도 분류: 벨만-푸앵카레 제로샷 분류기

## 1. 핵심 아이디어

기존 의도 분류는 flat한 클래스 공간을 가정하지만, 실제 의도는 계층적 구조를 가집니다. 하이퍼볼릭 공간의 지수적 확장 속성과 벨만 에너지 표면을 결합하여, 학습 없이도 계층적 의도를 분류하는 시스템을 제안합니다.

### 핵심 통찰

- **의도는 트리 구조**: 대분류(질문/요청/불만) → 중분류(계좌문의/송금/결제) → 소분류(잔액/한도/이체내역)
- **하이퍼볼릭 임베딩**: 푸앵카레 볼에서 트리 깊이 = 원점으로부터의 거리
- **벨만 에너지 지형**: 의도 노드를 에너지 최소점(Attractor)으로 표현
- **제로샷 추론**: 새 발화는 에너지 경사를 따라 자연스럽게 가장 가까운 의도로 흘러감

## 2. 수학적 정식화

### 2.1 의도 계층 임베딩

의도 트리 $\mathcal{T} = (V, E)$를 푸앵카레 볼 $\mathbb{B}^d$에 임베딩:

$$
\phi: V \to \mathbb{B}^d, \quad \text{s.t.} \quad \|\phi(v)\| \approx \frac{\text{depth}(v)}{\text{max\_depth}}
$$

루트에 가까운 대분류는 원점 근처, 말단 노드는 경계 근처에 배치됩니다.

### 2.2 벨만 포텐셜 필드

각 의도 노드 $v_k$를 중심으로 한 가우시안 포텐셜:

$$
V_k(x) = -\exp\left(-\frac{d_P(x, \phi(v_k))^2}{2\sigma_k^2}\right)
$$

여기서 $d_P$는 푸앵카레 거리, $\sigma_k$는 노드의 "영향 범위"(계층 수준에 비례).

전체 포텐셜:

$$
V_{\text{total}}(x) = \sum_{k} \alpha_k V_k(x) + \lambda \|\text{grad}_g V\|^2
$$

우항은 정규화 항(포텐셜 지형을 부드럽게 만듦).

### 2.3 측지선 흐름 분류

입력 발화 $u$를 인코더로 $x_0 \in \mathbb{B}^d$에 매핑한 후, 벨만-측지선 흐름:

$$
\frac{dx}{dt} = -G(x)^{-1} \nabla_x V_{\text{total}}(x)
$$

수렴점 $x^* = \lim_{t \to \infty} x(t)$와 가장 가까운 의도 노드가 예측 결과.

## 3. 아키텍처 설계

### 3.1 발화 인코더

```
입력 텍스트 → [BERT/DeBERTa] → 768d 벡터 → [Hyperbolic Projection] → 32d Poincaré 벡터
```

**Hyperbolic Projection**:

$$
x_{\text{hyp}} = \tanh(\|W z\| / c) \cdot \frac{W z}{\|W z\|}
$$

여기서 $z$는 유클리드 임베딩, $W$는 학습 가능한 투영 행렬.

### 3.2 의도 트리 구축

**자동 계층 발견**:

1. 기존 의도 레이블에서 WordNet/Word2Vec 유사도 기반 계층 트리 생성
2. Hyperbolic 트리 임베딩 알고리즘 (Nickel & Kiela, 2017) 사용
3. 각 노드에 학습 가능한 프로토타입 $\phi(v_k) \in \mathbb{B}^d$ 할당

**의도 트리 예시** (은행 챗봇):

```
Root
├─ 계좌문의 (r=0.3)
│  ├─ 잔액 (r=0.5)
│  ├─ 한도 (r=0.5)
│  └─ 거래내역 (r=0.5)
├─ 송금 (r=0.3)
│  ├─ 일반이체 (r=0.5)
│  ├─ 예약이체 (r=0.5)
│  └─ 자동이체 (r=0.5)
└─ 문의 (r=0.3)
   ├─ 영업점 (r=0.5)
   └─ 상담원연결 (r=0.5)
```

여기서 $r$은 푸앵카레 볼에서의 반경(원점으로부터의 거리).

### 3.3 추론 파이프라인

```python
def classify_intent(utterance, intent_tree, max_steps=10):
    x = encoder(utterance)
    
    for t in range(max_steps):
        V_total = sum(V_k(x) for k in intent_tree.nodes)
        grad_V = autograd(V_total, x)
        
        x = exponential_map(
            x, 
            -learning_rate * metric_inverse(x) @ grad_V
        )
        
        if converged(x):
            break
    
    return nearest_node(x, intent_tree)
```

**계산 복잡도**: $O(K \cdot d)$ (K = 노드 수, d = 차원)

일반 Transformer 분류기는 $O(L^2 \cdot d)$ (L = 시퀀스 길이) → 장문에 대해 10배 이상 빠름.

## 4. 제로샷 및 Few-Shot 학습

### 4.1 제로샷 시나리오

새로운 의도 클래스 추가 시:

1. 기존 트리에서 의미적으로 가장 가까운 부모 노드 찾기
2. 부모 위치에서 적절한 거리만큼 떨어진 곳에 새 노드 배치
3. 즉시 추론 가능 (재학습 불필요)

**예시**:
```
"해외송금" 의도 추가 → "송금" 노드 아래 자식으로 r=0.6에 배치
→ "해외로 돈 보내고 싶어요" 발화는 자동으로 해당 영역으로 흐름
```

### 4.2 Few-Shot 미세조정

각 새 클래스에 대해 5-10개 예시만으로 프로토타입 위치 조정:

$$
\phi(v_{\text{new}}) \leftarrow \text{Frechet Mean}_P \{ x_1, ..., x_n \}
$$

푸앵카레 거리 기반 평균 (일반 유클리드 평균이 아님).

## 5. 고급 기능

### 5.1 모호성 감지

수렴 속도가 느리거나 여러 Attractor 사이를 진동하면 모호한 발화로 판단:

$$
\text{Ambiguity} = \frac{1}{T} \sum_{t=0}^{T-1} \|x_{t+1} - x_t\|_P
$$

임계값 이상이면 "명확히 해주세요" 응답 생성.

### 5.2 계층 수준별 신뢰도

최종 위치 $x^*$와 각 계층의 프로토타입 거리:

```
Level 1 (대분류): 계좌문의  [신뢰도: 0.95]
Level 2 (중분류): 거래내역  [신뢰도: 0.78]
Level 3 (소분류): 입출금내역 [신뢰도: 0.62]
```

낮은 계층에서 신뢰도가 떨어지면 상위 계층 응답만 제공.

### 5.3 대화 맥락 통합

이전 발화들의 궤적을 momentum으로 활용:

$$
x_{t+1} = \text{Exp}_{x_t}\left( \beta v_t - \eta G^{-1} \nabla V \right)
$$

여기서 $v_t$는 직전 이동 방향(대화 맥락).

## 6. 실험 설계

### 6.1 데이터셋

- **CLINC150**: 150개 의도, 10개 도메인, 23,700 발화
- **Banking77**: 77개 은행 의도, 13,083 발화
- **ATIS**: 항공 예약, 26개 의도
- **자체 수집**: 한국어 은행 챗봇 로그 (계층 구조 명시)

### 6.2 베이스라인

1. Flat Softmax (BERT + Linear)
2. Hierarchical Softmax (BERT + Tree Softmax)
3. Siamese Network (Prototypical Networks)
4. SetFit (few-shot)

### 6.3 평가 지표

- **정확도**: Top-1, Top-3, Top-5
- **계층 정확도**: 각 레벨별 정확도
- **계층 거리**: 오답 시 실제 의도와의 트리 거리
- **제로샷 성능**: 10% 의도 제거 후 재배치
- **Few-Shot 성능**: 클래스당 5-shot 미세조정
- **추론 속도**: ms/sample (CPU/GPU)

### 6.4 예상 결과

| 지표 | Flat Softmax | Hierarchical Softmax | 제안 모델 |
|------|--------------|----------------------|----------|
| Top-1 정확도 | 85% | 87% | 89% |
| 제로샷 Top-1 | 0% | 15% | 67% |
| 5-shot Top-1 | 45% | 58% | 81% |
| 계층 거리 (오답 시) | 2.3 | 1.8 | 1.1 |
