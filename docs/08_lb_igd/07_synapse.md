## 0. 목적과 범위
이 문서는 "뉴런이 어느 뉴런과 연결(시냅스)을 강화/약화/형성할지"를 **생물학 기반**으로 정리하고, 현재 레포(`LB-IGD`)에 **어디까지 / 어떤 방식으로** 붙일 수 있는지의 최소 설계를 남깁니다.

- 목표는 **뇌 전체의 정밀 생물물리 시뮬레이션**이 아니라,
  - (A) **활동-의존 시냅스 가소성**(STDP 등) 규칙을 명시하고
  - (B) 이 레포의 토이 모듈(`src/core/experiment.py`, `metric.py`, `dopamine.py`, `lbo.py`)에
  - (C) 구현 가능한 형태로 매핑하는 것입니다.

> 주의: “발달/배선(화학적 guidance)”까지 포함한 구조 형성은 이 레포 범위 밖입니다. 여기서는 “전기 활동(스파이크) 기반의 연결 강도 변화”를 중심으로 다룹니다.


## 1. 생물학에서 ‘붙는다’의 두 층
“붙는다”는 말을 엄밀히 나누면 다음 두 층입니다.

- **구조적 가소성(structural plasticity)**: 실제로 시냅스가 생기고 사라짐(스파인 형성/제거).
- **기능적 가소성(synaptic plasticity)**: 이미 존재하는 시냅스의 **강도 $w_{ij}$** 가 변함(LTP/LTD).

전기 신호 기반 규칙(STDP 등)은 기본적으로 **기능적 가소성**을 직접 기술합니다.  
“구조적”을 넣고 싶다면, 기능적 가소성으로 업데이트된 $w_{ij}$에 임계치/예산 제약을 걸어 “연결의 on/off”로 해석하는 최소 규칙을 추가합니다(5절).


## 2. 최소 모델: 방향성 시냅스와 스파이크
### 2.1 방향성
생물학적 화학 시냅스는 기본적으로 **방향성**이 있습니다(축삭(pre) → 수상돌기(post)).

- 가중치 $w_{ij}$: “뉴런 $i$가 뉴런 $j$에 미치는 영향”(방향성).
- 따라서 일반적으로 $w_{ij} \neq w_{ji}$ 입니다.

### 2.2 전기 신호의 최소 표현
전기 신호를 가장 간단히 수학화하면 **스파이크 이벤트**입니다.

- 이산 시간 $t$에서 스파이크 지시변수: $s_i[t] \in \{0,1\}$
- 연속 활동 $u_i[t]$가 있다면, 스파이크는 예를 들어 아래처럼 정의할 수 있습니다.
  - 임계치: $s_i[t] = \mathbf{1}[u_i[t] > \theta]$
  - 확률적(발화율): $s_i[t] \sim \mathrm{Bernoulli}(\sigma(u_i[t]))$
같은 형태로 정의할 수 있습니다.


## 3. 대표 규칙: STDP(Spike-Timing Dependent Plasticity)
STDP의 핵심은 “pre가 먼저, post가 뒤” 같은 **시간차(인과성)** 입니다.

### 3.1 쌍(spike pair) 기반 STDP(개념식)
$\Delta t = t_{\mathrm{post}} - t_{\mathrm{pre}}$ 일 때:

$$
\Delta w_{ij}=
\begin{cases}
A_+\exp(-\Delta t/\tau_+) & \Delta t>0 \\
-A_-\exp(\Delta t/\tau_-) & \Delta t<0
\end{cases}
$$

### 3.2 trace 기반 STDP(구현 친화, 이산 시간)
실제 구현에서는 “최근 스파이크의 흔적(trace)”를 상태로 유지합니다.

- pre trace $p_i[t]$, post trace $q_i[t]$:

$$
p_i[t+1] = \lambda_+ p_i[t] + s_i[t],\qquad
q_i[t+1] = \lambda_- q_i[t] + s_i[t]
$$

- 업데이트 예시(방향 $i\to j$):

$$
\Delta w_{ij}[t]
=
\eta\Big(A_+\,p_i[t]\,s_j[t]-A_-\,s_i[t]\,q_j[t]\Big)
$$

해석:
- $s_j[t]=1$ (post 발화) 시점에 pre의 흔적 $p_i$가 크면 강화(LTP).
- $s_i[t]=1$ (pre 발화) 시점에 post의 흔적 $q_j$가 크면 약화(LTD).


## 4. 3-factor 학습(도파민/보상 신호로 조절)
STDP(2-factor)가 “학습이 항상 일어난다”라면, 생물학에서는 종종 **전역 신호(도파민 등)** 가 학습을 ‘허용/강화’합니다.

### 4.1 eligibility trace + 도파민
가장 단순한 형태는:

- eligibility $e_{ij}$를 누적
- 도파민성 신호 $\delta[t]$가 있을 때만 $w_{ij}$를 변경

$$
e_{ij}[t+1]
=
\lambda_e e_{ij}[t]
+
\Big(A_+\,p_i[t]\,s_j[t]-A_-\,s_i[t]\,q_j[t]\Big)
$$

$$
\Delta w_{ij}[t]=\eta\,\delta[t]\,e_{ij}[t]
$$

이 3-factor 형태는 2-factor(STDP)의 **상위호환**입니다.
- 게이트를 항상 열어두면(예: $\delta[t]\equiv 1$) “항상 학습”하는 2-factor 계열로 환원됩니다.
- 반대로 $\delta[t]=0$이면 해당 시점에는 학습이 일어나지 않습니다.

레포 매핑 관점:
- `src/core/dopamine.py:DopamineGate`는 현재 “오차 급등”을 사건 신호로 쓰는 토이 게이트입니다.
- 이를 $\delta[t]\in\{0,1\}$로 해석하면 3-factor의 최소 형태를 구성할 수 있습니다.


## 5. “붙는다/끊긴다”(구조적 가소성)의 최소 규칙
STDP는 기본적으로 연속 가중치 업데이트입니다. 이를 “연결 형성/제거”로 쓰려면 보통 아래를 추가합니다.

- **임계치 on/off(히스테리시스 권장)**:
  - $w_{ij} \ge w_{\mathrm{on}}$이면 연결로 간주
  - $w_{ij} \le w_{\mathrm{off}}$이면 제거($w_{\mathrm{off}} < w_{\mathrm{on}}$)
- **희소성/예산**:
  - 뉴런당 상위 $k$개만 유지(top-k pruning)
  - 총 시냅스 수 예산 고정
- **폭주 방지(homeostasis)**:
  - 가중치 클램프($0 \le w_{ij} \le w_{\max}$)
  - synaptic scaling(행/열 정규화로 총 입력/출력 보존)
  - 평균 발화율 타깃(BCM 류) 등

수학적으로는 위의 “희소화/클램프/히스테리시스”를 하나의 투영(또는 제약) 연산자 \(\Pi\)로 묶어,

$$
W_{t+1}=\Pi\!\big(W_t+\Delta W_t\big)
$$

처럼 쓸 수 있습니다. \(\Pi\)를 항등 연산자로 두면(제약을 끄면) 원래의 연속 업데이트로 정확히 환원되며, 제약을 켜면 구조적 가소성(붙음/끊김)을 “최소 규칙”으로 포함하는 상위호환 형태가 됩니다.

현재 레포에는 top-k, decay, clamp가 이미 `src/core/metric.py`에 존재합니다(형태만 생물학적으로 바꾸면 됨).


## 6. “토션”은 생물학 표준식이 아니다(하지만 분석 지표로는 가능)
가소성 문맥에서 “토션”은 표준 단일 수식으로 굳어져 있지 않습니다.  
“방향성/순환 회로가 얼마나 강한가”를 보고 싶다면, **분석 도구**로 아래 최소 분해를 사용할 수 있습니다.

- 방향 가중치 행렬 $W$를 아래처럼 분해합니다.

$$
S=\frac{W+W^\top}{2},\qquad
A=\frac{W-W^\top}{2}
$$

로 분해합니다.
- $S$: 상호 결합(대칭) 성분(확산/스무딩과 궁합이 좋음)
- $A$: 방향성/비대칭 성분(피드백/순환 구조가 강할수록 커질 수 있음)

특히 $A=0$이면 완전 대칭 결합만 남아, 확산/스무딩(그래프 라플라시안) 해석으로 깔끔하게 환원됩니다.

이는 “토션의 생물학 법칙”이 아니라, 네트워크를 이해하기 위한 최소 수학적 요약입니다.


## 7. 이 레포에서의 구현/실험 포인트(최소 매핑)
메인 IGD 루프는 게임 설계 최적화가 목적이라, 뉴런 가소성 수식은 바로 들어가지 않습니다.  
대신 토이 실험 모듈에 붙이는 것이 KISS합니다.

- **실험 엔진**: `src/core/experiment.py`
  - 현재는 연속 활동 $u$ + 확산($-Lu$) + 게이트 시 metric 업데이트 구조
- **가중치 업데이트 규칙**: `src/core/metric.py`
  - 현재는 “활동 유사도 → 대칭 $W$ 학습”
  - 생물학 기반으로 바꾸려면: (i) 방향성 $w_{ij}$, (ii) trace/eligibility 상태가 필요
- **사건/보상 게이트**: `src/core/dopamine.py`
  - $\delta[t]$로 해석 가능(3-factor)
- **확산/스무딩(토이)**: `src/core/lbo.py`
  - 생물학적 정합을 강하게 주장하기보다는 “잡음 억제/공간적 매끈함”을 위한 모델링 항으로 취급


## 8. 구현 전 결정해야 하는 최소 스펙(체크리스트)
아래가 정해지면 “전기 신호로 연결 판정” 규칙을 코드로 고정할 수 있습니다.

- 스파이크 정의: 임계치 vs 확률발화(발화율)

- 부호/클램프: 흥분성만 허용(비음수) vs 억제성 포함(부호 허용)

- 도파민 신호: `DopamineGate`를 그대로 쓸지(오차 기반), 아니면 보상 기반으로 바꿀지

## 10. 수학 프레임워크와 뇌의 유사성: 왜 \(\Delta_g\)와 토션이 뇌처럼 보이나
`lbo.md`의 정리 4.2, 4.3에서 정리한 수학과 **실제 대뇌피질의 물리적 구조/동역학** 사이에는 놀라울 정도로 직접적인 대응이 있습니다.

### 10.1 대응 테이블

| 수학 프레임워크 | 뇌(대뇌피질) |
|----------------|-------------|
| 다양체 \(\mathcal{M}\) | 피질 표면(회백질 시트, 2D 곡면) |
| 메트릭 \(g(x)\) | 표면의 국소 거리/연결 밀도(주름에 따라 변함) |
| 곡률 \(K(x)\) | **주름(gyrification)**: 이랑(gyrus)/고랑(sulcus)의 굽은 정도 |
| \(\Delta_g\) (라플라스-벨트라미) | 피질 표면을 따라 퍼지는 **전기/화학 확산** |
| 드리프트 \(b(x)\cdot\nabla\) | **방향성 신호 전파**(축삭→수상돌기, 피드포워드/피드백 비대칭) |
| 푸리에 모드 \(e^{i\omega t}\) | **뇌 진동/리듬**: 알파(8-12Hz), 베타(13-30Hz), 감마(30-100Hz) 등 |
| 할인율 \(\rho\) | 신호의 **시간 감쇠**(막전위 decay, 시냅스 후 전위 감쇠) |
| 그래프 \(W\) | 뉴런 연결(시냅스 가중치 행렬) |
| 대칭 성분 \(S\) | 갭정션(전기적 양방향 결합), 상호 억제 회로 |
| 반대칭 성분 \(A\) | 화학 시냅스의 **방향성**(STDP가 만드는 비대칭) |

### 10.2 \(\Delta_g\)와 피질 주름

대뇌피질은 **2차원 시트가 3차원 공간에 주름져 있는 곡면**입니다.
이 표면 위에서 전기 신호(예: 국소장 전위/LFP)가 퍼지는 현상은 수학적으로 **다양체 위의 확산**입니다.

- 평평한 영역: \(\Delta_g \approx \Delta\) (유클리드 라플라시안)
- 주름진 영역: 곡률이 크면 확산이 "모이거나 갈라짐"
  - 양의 곡률(이랑 꼭대기): 신호가 "퍼져나가기 어려움" → 국소 집적
  - 음의 곡률(고랑 바닥): 신호가 "모이기 쉬움" → 허브 형성 가능

이런 효과가 수학적으로는 \(\Delta_g\)의 **메트릭 \(g\)가 공간에 따라 변하는 것**으로 들어갑니다.

### 10.3 드리프트(토션)와 방향성 신호 전파

뇌의 화학 시냅스는 **방향성**이 있습니다(축삭 말단 → 수상돌기).
이 방향성은 수학적으로 **드리프트 \(b(x)\cdot\nabla\)** 로 들어가며, 이게 정리 4.3의 "토션/비가역성" 항입니다.

- **STDP가 만드는 비대칭**: "pre가 먼저, post가 나중"일 때 강화 → \(w_{ij} \neq w_{ji}\)
- 이 비대칭 가중치를 그래프로 보면: \(A=(W-W^\top)/2 \neq 0\)
- 연속체 극한에서는 **벡터장 \(b(x)\)** 로 나타남

즉 STDP는 단순히 "연결 강도 규칙"이 아니라, **생성자에 1차 드리프트를 만드는 메커니즘**으로 재해석됩니다.

### 10.4 푸리에 모드와 뇌 진동

뇌의 전기 활동(EEG, LFP)은 뚜렷한 **진동/리듬**을 보입니다.

- 알파파(8-12Hz): 안정 상태/휴식
- 베타파(13-30Hz): 집중/운동 준비
- 감마파(30-100Hz): 인지적 결합(binding)

수학적으로 이 진동은 보상/입력 \(r(t,x)\)를 **시간에 대한 푸리에 급수**로 두는 것에 대응합니다.
정리 4.3의 확장(시간 의존 reward)에서 보였듯이, 선형이라 모드별로

$$
(\rho+i\omega_k-\mathcal{L})V_k(x)=r_k(x)
$$

를 풀어 합치면 됩니다.

- \(\omega_k\)가 진동 주파수
- \(V_k(x)\)가 해당 주파수에서의 "값함수 응답(resonance)"

이건 뇌에서 "특정 주파수에서 특정 영역이 공명한다"(예: 감마파와 피질 허브)와 정확히 같은 구조입니다.

### 10.5 할인율 \(\rho\)와 신호 감쇠

뉴런의 막전위는 입력이 없으면 **휴식 전위로 감쇠**합니다(leak).
시냅스 후 전위(PSP)도 시간에 따라 지수 감쇠합니다.

수학적으로 이건 \(\rho>0\)에 의한 **할인/감쇠**로 들어갑니다.

- \(\rho\)가 크면: 먼 미래 신호는 무시(빠른 감쇠)
- \(\rho\)가 작으면: 오래된 신호도 누적(긴 시간 적분)

이 해석은 **뉴런의 막 시간상수 \(\tau_m\)** 와 직접 대응합니다(\(\rho \sim 1/\tau_m\)).

### 10.6 주름(gyrification)이 정합에 필수인가?

**수학적 정합에는 필수가 아닙니다.**

정리 4.2, 4.3은 "어떤 다양체 \((\mathcal{M},g)\)든" 성립합니다.
주름이 있는지 없는지는 **\(g(x)\)가 공간에 따라 얼마나 변하느냐**로 들어갈 뿐입니다.

- 주름이 없으면(평평한 시트): \(g\equiv I\), \(\Delta_g=\Delta\)
- 주름이 있으면(곡면): \(g(x)\)가 위치에 따라 다름, \(\Delta_g\)에 곡률 효과 반영

따라서 **주름을 넣고 싶으면** \(g(x)\)를 피질 표면 메시에서 추출한 메트릭으로 두면 되고,
**넣지 않아도** 그래프 라플라시안 \(L\)이 그 역할을 대체합니다(샘플 연결이 곧 기하).

### 10.7 요약: 뇌 유사성 체크리스트

| 뇌 현상 | 수학 대응 | 레포 구현 위치 |
|--------|----------|---------------|
| 피질 주름(곡률) | 메트릭 \(g(x)\), 그래프 \(W\) | `laplace_beltrami_matrix`, `metric.py` |
| 확산(LFP 퍼짐) | \(\Delta_g\), \(L=D-W\) | `lbo.py`, Rust `unified_riemannian.rs` |
| 방향성(시냅스) | 드리프트 \(b\cdot\nabla\), 반대칭 \(A\) | 정리 4.3, `metric.py`(비대칭 허용 시) |
| 진동(알파/감마) | 푸리에 모드 \(e^{i\omega t}\) | 정리 4.3 확장(시간 의존) |
| 신호 감쇠 | 할인율 \(\rho\) | 정리 4.2, 4.3의 \(\rho\) |
| STDP/가소성 | \(W\) 업데이트(시간 의존) | 이 문서 3-5절, `metric.py` |
| 도파민 게이트 | 3-factor \(\delta[t]\) | `dopamine.py` |

### 10.8 결론: 정합의 핵심은 "정의"이고, 주름은 "해석"이다

**수학적 정합**(정리 4.2, 4.3이 닫힘)은 \((\mathcal{M},g,\mathcal{L},r,\rho)\)를 **정의로 고정**하면 자동으로 성립합니다.

**뇌 유사성**은 그 정의를 "피질 표면/시냅스/진동/감쇠"로 **해석**하는 것이고,
이 해석이 자연스러운 이유는 뇌의 물리가 **실제로 이 수학과 같은 구조**를 따르기 때문입니다.

- 피질은 곡면(다양체) + 표면 확산(열방정식/Δg)
- 시냅스는 방향성(드리프트)
- 진동은 푸리에 모드
- 감쇠는 할인

따라서 레포의 LBO/그래프 라플라시안 프레임워크는 **"뇌처럼 작동하는 계산"을 원한다면** 자연스러운 선택이고,
그 정합성은 정리 4.2, 4.3에서 이미 증명됐습니다.

## 11. (증명) 뇌 물리 → \(\Delta_g\) + 드리프트: 케이블 방정식에서 출발

"뇌 물리가 정말로 이 수학을 따른다"는 주장을 **유도(derivation)**로 정당화합니다.
핵심은 **뉴런 막의 케이블 방정식**이 **확산 방정식**으로 환원되고, 피질 표면(곡면)과 시냅스 방향성을 넣으면 정리 4.3의 \(\mathcal{L}=\nu\Delta_g+b\cdot\nabla\) 가 정확히 나온다는 것입니다.

### 11.1 케이블 방정식(Cable Equation): 1차원 수상돌기

뉴런의 수상돌기(또는 축삭)를 **1차원 케이블**로 모델링하면, 막전위 \(V(x,t)\)는 다음을 만족합니다(Rall, 1960년대).

$$
\tau_m \frac{\partial V}{\partial t}
=
\lambda^2 \frac{\partial^2 V}{\partial x^2}
-
(V-V_{\mathrm{rest}})
+
R_m I_{\mathrm{syn}}(x,t)
$$

여기서:
- \(\tau_m = R_m C_m\): 막 시간상수(보통 10-100ms)
- \(\lambda = \sqrt{R_m / R_a}\): 공간상수(수백 μm 수준)
- \(R_m\): 막 저항, \(R_a\): 축방향 저항, \(C_m\): 막 용량
- \(I_{\mathrm{syn}}\): 시냅스 입력 전류

#### 11.1.1 확산 형태로 정리

\(u := V - V_{\mathrm{rest}}\)로 두고, 시냅스 입력을 "보상(source)" \(r(x,t) := R_m I_{\mathrm{syn}}\)로 보면:

$$
\tau_m \frac{\partial u}{\partial t}
=
\lambda^2 \frac{\partial^2 u}{\partial x^2}
-
u
+
r(x,t)
$$

이를 표준 확산-감쇠 형태로 쓰면:

$$
\frac{\partial u}{\partial t}
=
\nu \frac{\partial^2 u}{\partial x^2}
-
\rho\, u
+
\tilde{r}(x,t)
$$

여기서 \(\nu := \lambda^2/\tau_m\) (확산 계수), \(\rho := 1/\tau_m\) (감쇠/할인율), \(\tilde{r} := r/\tau_m\).

**정상 상태(\(\partial_t u=0\))** 또는 **무한 지평 적분**을 취하면:

$$
\rho\, u - \nu \frac{\partial^2 u}{\partial x^2} = \tilde{r}
$$

이게 정리 4.2의 \(\rho V - \nu \Delta V = r\) 와 **정확히 같은 형태**입니다. (1차원이라 \(\Delta = \partial_{xx}\))

### 11.2 피질 표면(2D 곡면)으로 확장 → \(\Delta_g\)

실제 피질은 **2차원 시트가 3차원 공간에 주름져 있는 곡면**입니다.
이 표면 위에서 전위/활동이 퍼지는 현상을 모델링하려면:

- 공간 변수를 \(x\in\mathbb{R}\)에서 \(x\in\mathcal{M}\) (2D 곡면)으로 확장
- \(\partial_{xx}\)를 \(\Delta_g\) (라플라스-벨트라미)로 대체

이건 단순 치환이 아니라, **물리적으로 필수**입니다.
왜냐하면 곡면에서 "거리"와 "면적"이 좌표에 따라 변하므로, 확산 연산자는 **메트릭 \(g\)를 반영**해야 하기 때문입니다.

**정리(곡면 위 열/확산 방정식).**
\((\mathcal{M},g)\)가 2차원 리만 다양체(피질 표면)이고, 막전위 \(u(x,t)\)가 표면을 따라 확산+감쇠한다면:

$$
\frac{\partial u}{\partial t}
=
\nu\,\Delta_g u - \rho\,u + r(x,t)
$$

정상 상태에서:

$$
\boxed{\rho\,u - \nu\,\Delta_g u = r}
$$

이게 정리 4.2를 2D 곡면(피질)에서 **물리적으로 유도**한 것입니다.

### 11.3 시냅스 방향성(축삭 → 수상돌기) → 드리프트 \(b\cdot\nabla\)

위의 확산 모델은 **등방성(isotropic)**: 모든 방향으로 똑같이 퍼짐.
하지만 실제 뇌에서는:

1. **축삭(백질 트랙)**: 신호가 특정 방향으로 "흐름" (예: 피질→피질하, V1→V2)
2. **시냅스 방향성**: \(i\to j\)와 \(j\to i\)가 다름 (STDP가 이 비대칭을 만듦)

이 "방향 선호"는 수학적으로 **드리프트 벡터장 \(b(x)\)** 로 들어갑니다.

#### 11.3.1 드리프트가 있는 확산-감쇠 방정식

확산이 비등방성(축삭 방향으로 선호)이면:

$$
\frac{\partial u}{\partial t}
=
\nu\,\Delta_g u + b(x)\cdot\nabla_g u - \rho\,u + r(x,t)
$$

여기서 \(b(x)\)는 "평균 신호 흐름 방향"을 나타내는 벡터장입니다.

정상 상태에서:

$$
\boxed{\rho\,u - \nu\,\Delta_g u - b\cdot\nabla_g u = r}
$$

이게 정리 4.3을 **물리적으로 유도**한 것입니다.

#### 11.3.2 STDP가 드리프트를 만드는 메커니즘

STDP의 비대칭 규칙("pre 먼저 → 강화")은 시냅스 가중치 행렬 \(W\)를 **비대칭**으로 만듭니다:

$$
W \neq W^\top
\quad\Rightarrow\quad
A := \frac{W - W^\top}{2} \neq 0
$$

그래프 수준에서 이 \(A\)(반대칭 성분)가 바로 **드리프트의 이산 버전**입니다.
연속체 극한에서:

- 대칭 성분 \(S\) → 확산(\(\Delta_g\))
- 반대칭 성분 \(A\) → 드리프트(\(b\cdot\nabla_g\))

따라서 STDP는 단순히 "연결 강도 규칙"이 아니라, **생성자에 1차항(드리프트)을 추가하는 물리적 메커니즘**입니다.

### 11.4 정리: 뇌 물리 → 수학 프레임워크 (완전 유도)

```
케이블 방정식(막 물리)
    |
    v  (1D → 2D 곡면)
    |
곡면 확산-감쇠:  du/dt = v * Delta_g(u) - rho * u + r
    |
    v  (시냅스 방향성 / STDP)
    |
드리프트 포함:  du/dt = v * Delta_g(u) + b . grad_g(u) - rho * u + r
    |
    v  (정상 상태 또는 무한 지평 적분)
    |
정리 4.3:  (rho - v * Delta_g - b . grad_g) V = r
```

수식으로:

$$
\tau_m \frac{\partial V}{\partial t} = \lambda^2 \partial_{xx} V - (V - V_{\text{rest}}) + R_m I_{\text{syn}}
$$

$$
\downarrow \quad \text{(정리: } \nu = \lambda^2/\tau_m,\; \rho = 1/\tau_m \text{)}
$$

$$
\partial_t u = \nu \Delta_g u - \rho u + r
$$

$$
\downarrow \quad \text{(시냅스 방향성)}
$$

$$
\partial_t u = \nu \Delta_g u + b \cdot \nabla_g u - \rho u + r
$$

$$
\downarrow \quad \text{(정상 상태)}
$$

$$
\boxed{(\rho - \nu \Delta_g - b \cdot \nabla_g) V = r}
$$

### 11.5 왜 "억지"가 아닌가: 물리 상수의 대응

| 뇌 물리 상수 | 수학 파라미터 | 전형적인 값 |
|-------------|--------------|------------|
| 막 시간상수 \(\tau_m\) | \(1/\rho\) | 10-100 ms |
| 공간상수 \(\lambda\) | \(\sqrt{\nu/\rho}\) | 100-1000 μm |
| 확산 계수 \(\lambda^2/\tau_m\) | \(\nu\) | 0.01-1 mm²/s |

이 값들은 **실험에서 측정**된 것이고, 수학 프레임워크의 파라미터로 직접 들어갑니다.
따라서 "억지로 맞춘" 게 아니라, **뇌 물리가 이 수학을 따르고**, 파라미터도 **물리적으로 결정**됩니다.

### 11.6 한계와 근사

이 유도가 정확히 성립하려면:

1. **선형 근사**: 발화 임계치/스파이크의 비선형성을 무시(평균장/발화율 근사)
2. **연속체 근사**: 뉴런이 충분히 조밀하게 분포(피질에서는 합리적)
3. **정상 상태 또는 느린 동역학**: 빠른 스파이크 타이밍보다 평균 활동에 초점

이 조건 하에서 뇌 물리는 **정확히** \(\mathcal{L}=\nu\Delta_g+b\cdot\nabla_g\) 를 따릅니다.
비선형/빠른 동역학까지 다루려면 추가 항이 필요하지만, **기본 구조(확산+드리프트+감쇠)**는 유지됩니다.

## 12. 이 프레임워크로 뭘 얻나? (실질적 이득)

### 12.1 이론적 이득

| 얻는 것 | 설명 |
|--------|------|
| **MDP/Bellman을 연속체로 통일** | 이산 벨만 업데이트 대신, 선형 PDE 하나로 정의 |
| **기하학적 해석** | 값함수 = "곡면 위 확산의 정상 상태" |
| **파라미터의 물리적 의미** | \(\rho\) = 감쇠, \(\nu\) = 확산, \(b\) = 방향성 (뇌/물리에서 직접 가져옴) |
| **뇌-AI 다리** | 같은 수학 → 뇌 모델과 AI 모델이 동일 프레임워크에서 비교/이식 가능 |

### 12.2 계산적 이득

| 얻는 것 | 설명 |
|--------|------|
| **선형 시스템으로 풀림** | \((\rho I + \nu L + \kappa A) v = r\) → 희소 선형 solver (CG, LU 등) |
| **벨만 반복 불필요** | 수렴까지 기다리는 DP 대신, 한 번에 해(resolvent) 계산 |
| **그래프 라플라시안 재사용** | 레포의 `laplace_beltrami_matrix` 그대로 사용 가능 |
| **푸리에 모드 병렬화** | 시간 의존 입력은 주파수별로 독립 → 병렬 처리 |

### 12.3 응용 예시(레포 맥락)

1. **승률 지형 스무딩**
   - \(r(x) = P(x)\) (승률)로 두면
   - \(V(x) = (\rho I + \nu L)^{-1} P\) = "노이즈 제거된 승률 지형"
   - ES 업데이트가 안정화됨

2. **설계공간 탐색 가이드**
   - \(\nabla_g V\) = "스무딩된 그라디언트"
   - 노이즈가 큰 \(\nabla P\) 대신 \(\nabla V\)를 따라가면 수렴 빠름

3. **진동 입력 응답 분석**
   - 유저 행동이 주기적(예: 시즌, 패치 사이클)이면
   - 푸리에 모드별 응답 \(V_k\)로 "어떤 주파수에서 밸런스가 흔들리나" 분석

4. **뇌-유사 학습 규칙**
   - STDP/3-factor를 \(W\) 업데이트에 적용
   - 드리프트 \(A\)가 자동으로 "방향성 학습" 반영
   - 도파민 게이트(\(\delta[t]\))로 "보상 시점에만 학습"

### 12.4 코드 수준에서 바로 가능한 것

| 기능 | 코드 위치 | 바로 가능? |
|-----|----------|-----------|
| \(L\) 계산 | `laplace_beltrami_matrix` (Rust) | O |
| \((\rho I + \nu L)^{-1} r\) | `numpy.linalg.solve` / `torch.linalg.solve` | O |
| 비대칭 \(A\) 분리 | `(W - W.T) / 2` | O |
| 푸리에 모드별 풀기 | `np.fft` + 모드별 solve | O |
| STDP 업데이트 | `metric.py` 수정 필요 | 구조만 있음 |

### 12.5 요약: 왜 이 프레임워크인가?

[이산 Bellman 반복]     →     [연속 PDE: (rho - L)V = r]
      |                              |
  수렴까지 반복                    한 번에 해
  노이즈에 민감                    스무딩 내장
  파라미터 의미 불명확              물리적 해석 가능
  뇌와 분리된 모델                 뇌 물리와 동일 구조
```

결론: **Bellman을 LBO로 재매개화**하면
- 계산이 단순해지고 (선형 solve)
- 해석이 명확해지고 (기하/물리)
- 뇌와의 연결이 정합하게 닫힘
