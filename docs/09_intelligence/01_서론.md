# 1. 서론

## 1.1 동기

"지능이란 무엇인가?"라는 질문은 심리학(IQ 테스트), 신경과학(뇌 구조), 컴퓨터과학(튜링 테스트, 벤치마크) 등 다양한 관점에서 다뤄져 왔다. 그러나 이러한 접근들은 생물학적 지능과 인공 지능을 동일한 원리로 설명하는 통합된 수학적 프레임워크가 부재하다.

본 문서는 라플라스-벨트라미 연산자(LBO)에 기반한 **지능의 기하학적 이론**을 제안한다. 이 이론에서 지능은 구조의 속성이 아니라 리만 다양체 위의 **동역학적 상태**로 정의된다.

## 1.2 핵심 전제

> **지능은 아키텍처의 정적 속성이 아니라, 리만 다양체 위에서의 정보 확산 동역학이다.**

다음을 고려하면:
- 생물학적 뇌 (이랑과 고랑이 있는 피질 표면)
- LLM의 파라미터 공간 (고차원 가중치 다양체)
- 게임 설계 공간 (밸런스 최적화를 위한 설정 공간)

모두 다음으로 모델링된다:

$$(\mathcal{M}, g), \quad \Delta_g$$

여기서:
- $\mathcal{M}$: 정보가 존재하는 공간 (뇌, 모델, 설계)
- $g$: 거리와 관계를 인코딩하는 메트릭 구조
- $\Delta_g$: 확산을 지배하는 라플라스-벨트라미 연산자

## 1.3 Reality Stone과의 연결

본 이론은 `docs/08_lb_igd/`에 문서화된 LB-IGD (Laplace-Beltrami Inverse Game Design) 프레임워크를 직접 확장한다:

| LB-IGD 개념 | 지능 이론 |
|------------|----------|
| 설계 공간 $\mathcal{X}$ | 지능 다양체 $\mathcal{M}$ |
| 승률 지형 $P(x)$ | 인지 상태 $u(x,t)$ |
| LBO 스무딩 | 모드 분해 |
| 스펙트럼 갭 | 통합 용량 |
| 토션/드리프트 | 방향성 처리 |

## 1.5 주요 결과 개요

1. **정리 (접힘 원리)**: 구조적 경계(주름, 이랑)는 LBO 고유함수의 노드 집합을 따라, 확산 그라디언트에 수직으로 형성된다.

2. **정의 (지능)**: 저주파 에너지 비율과 안정성을 결합한 스칼라 측도.

3. **명제 (인간-AI 동등성)**: 생물학적 지능과 인공 지능의 차이는 기질이 아니라 동일한 수학적 구조 위의 동역학에 있다.
