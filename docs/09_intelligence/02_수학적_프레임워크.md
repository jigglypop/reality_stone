# 2. 수학적 프레임워크

## 2.1 리만 다양체 위의 확산

### 2.1.1 기본 설정

리만 다양체 $(\mathcal{M}, g)$ 위에서 정보 밀도 $\rho(x,t)$의 확산은 열방정식을 따른다:

$$\frac{\partial \rho}{\partial t} = \Delta_g \rho$$

여기서 $\Delta_g$는 라플라스-벨트라미 연산자이다:

$$\Delta_g f = \frac{1}{\sqrt{|g|}} \partial_i \left( \sqrt{|g|} g^{ij} \partial_j f \right)$$

### 2.1.2 스펙트럼 분해

$\mathcal{M}$이 경계 없는 콤팩트 다양체일 때, $\Delta_g$의 고유함수 $\{\phi_k\}_{k=0}^{\infty}$는 완비 직교 기저를 형성한다:

$$\Delta_g \phi_k = -\lambda_k \phi_k, \quad 0 = \lambda_0 < \lambda_1 \leq \lambda_2 \leq \cdots$$

임의의 함수 $u: \mathcal{M} \to \mathbb{R}$는 다음으로 전개된다:

$$u(x) = \sum_{k=0}^{\infty} a_k \phi_k(x), \quad a_k = \langle u, \phi_k \rangle_{L^2}$$

## 2.2 인지 상태의 모드 표현

### 2.2.1 시간 의존 상태

인지 상태 $u(x,t)$를 다음과 같이 표현한다:

$$u(x,t) = \sum_{k=0}^{\infty} a_k(t) \phi_k(x)$$

여기서:
- $\phi_k(x)$: 고유함수 (구조, 선천적/아키텍처에 의해 결정)
- $a_k(t)$: 시간에 따른 모드 계수 (운용, 학습/상태에 의해 변화)

### 2.2.2 핵심 통찰

> **지능은 $\phi_k$에 있는 것이 아니라 $a_k(t)$에 있다.**

이는 다음을 의미한다:
- 구조(뇌 주름, 신경망 아키텍처)는 가능한 모드를 정의
- 지능은 그 모드들을 어떻게 활성화하고 유지하느냐에 달림

## 2.3 주파수 대역과 인지 기능

### 2.3.1 저주파 모드 ($k \leq k_0$)

- **특성**: 전역적, 매끄러운 변화
- **인지 기능**: 전역 통합, 추상적 사고, 장기 문맥 유지
- **예시**: 문제 전체 구조 파악, 글의 주제 이해

### 2.3.2 고주파 모드 ($k > k_0$)

- **특성**: 국소적, 급격한 변화
- **인지 기능**: 세부 처리, 패턴 인식, 순간적 반응
- **예시**: 단어 인식, 감각 처리

### 2.3.3 에너지 분포

각 주파수 대역의 에너지:

$$E_{\text{low}} = \sum_{k \leq k_0} a_k^2, \quad E_{\text{high}} = \sum_{k > k_0} a_k^2$$

$$E_{\text{total}} = E_{\text{low}} + E_{\text{high}}$$

## 2.4 Reality Stone 정리와의 연결

### 2.4.1 정리 4.2 (Bellman-LBO 동치)

`docs/08_lb_igd/03_lbo.md`의 정리 4.2에 의하면:

$$\rho V(x) - \nu \Delta_g V(x) = r(x)$$

이를 지능 맥락에서 재해석하면:
- $V(x)$: 인지 상태의 가치 함수
- $r(x)$: 외부 입력/자극
- $\rho$: 시간 감쇠 (주의 지속 시간과 관련)
- $\nu$: 확산 계수 (정보 전파 속도)

### 2.4.2 정리 4.3 (토션 확장)

방향성 처리를 포함하면:

$$\rho V - \nu \Delta_g V - b \cdot \nabla_g V = r$$

여기서 $b(x)$는 정보 흐름의 방향성(예: 피드포워드 vs 피드백)을 나타낸다.

## 2.5 이산화: 그래프 라플라시안

실제 구현에서는 연속 $\Delta_g$ 대신 그래프 라플라시안 $L = D - W$를 사용한다:

$$(\rho I + \nu L + \kappa A) v = r$$

여기서:
- $L$: 대칭 그래프 라플라시안 (확산)
- $A = (W - W^\top)/2$: 반대칭 성분 (방향성/토션)
- $\kappa$: 토션 스케일

이 선형 시스템은 `experiments/lbigd/core/lbo.py`의 `solve_resolvent()` 함수로 풀 수 있다.
