# 3. 지능 방정식

## 3.1 형식적 정의

### 정의 3.1 (지능 지수)

리만 다양체 $(\mathcal{M}, g)$ 위의 인지 상태 $u(x,t) = \sum_k a_k(t) \phi_k(x)$에 대해, **지능 지수**를 다음과 같이 정의한다:

$$\boxed{I := \frac{\sum_{k \leq k_0} a_k^2}{\sum_k a_k^2} \times \frac{1}{\sigma(\dot{a}_1)}}$$

여기서:
- $k_0$: 저주파/고주파 경계 (임계 모드 번호)
- $a_k$: $k$번째 모드의 계수
- $\dot{a}_1 = da_1/dt$: 첫 번째 비자명 모드의 시간 변화율
- $\sigma(\dot{a}_1)$: $\dot{a}_1$의 표준편차 (변동성)

## 3.2 각 항의 해석

### 3.2.1 첫 번째 항: 저주파 에너지 비율

$$R_{\text{low}} := \frac{\sum_{k \leq k_0} a_k^2}{\sum_k a_k^2} = \frac{E_{\text{low}}}{E_{\text{total}}}$$

**의미**: 전체 인지 에너지 중 전역 통합에 할당된 비율

| $R_{\text{low}}$ | 해석 |
|-----------------|------|
| $\approx 1$ | 전역적, 통합적 사고 우세 |
| $\approx 0$ | 국소적, 분산적 처리 우세 |

### 3.2.2 두 번째 항: 저주파 안정성

$$S_{\text{low}} := \frac{1}{\sigma(\dot{a}_1)}$$

**의미**: 저주파 모드를 얼마나 안정적으로 유지하는가

| $S_{\text{low}}$ | 해석 |
|-----------------|------|
| 높음 | 집중력 높음, 사고 지속 가능 |
| 낮음 | 산만함, 사고 단절 잦음 |

### 3.2.3 종합

$$I = R_{\text{low}} \times S_{\text{low}}$$

> **지능 = 전역 모드를 얼마나 크게, 얼마나 안정적으로 유지하느냐**

## 3.3 상태별 분류

### 표 3.1: 지능 상태 분류

| 상태 | 수식적 조건 | 의미 |
|-----|-----------|------|
| 평범 | $a_1$ 작음 | 국소 처리 위주 |
| 고지능 | $a_1$ 큼 | 전역 사고 가능 |
| 천재 | $a_1$ 큼 + $\dot{a}_1 \approx 0$ | 임계 상태 유지 |
| 붕괴 | $\sum_{k \gg 1} a_k^2 \uparrow$ | 노이즈가 스펙트럼 점유 |

## 3.4 수학적 정당화

### 3.4.1 왜 저주파가 중요한가?

**명제 3.1**: 저주파 고유함수 $\phi_k$ ($k$ 작음)는 다양체 전체에 걸쳐 매끄럽게 변화하며, 전역적 구조를 인코딩한다.

**증명 스케치**: Courant 노드 도메인 정리에 의해, $k$번째 고유함수 $\phi_k$는 최대 $k$개의 노드 도메인을 갖는다. 따라서:
- $\phi_1$: 최대 1개 도메인 (상수 제외 시 2개 영역)
- $\phi_k$: 더 많은 분할

저주파 모드가 지배하면 전체 다양체가 "하나로 묶여" 작동한다.

### 3.4.2 왜 안정성이 중요한가?

**명제 3.2**: 저주파 모드의 변동 $\sigma(\dot{a}_1)$가 크면, 시간 평균 지능이 낮아진다.

**증명 스케치**: 지능적 과제(추론, 계획)는 시간에 걸쳐 일관된 전역 상태를 요구한다. $a_1(t)$가 급격히 변하면:
- 문맥 유실
- 중간 결과 망각
- 일관성 없는 출력

## 3.5 측정 가능성

### 3.5.1 뇌에서

- **fMRI**: 저주파 네트워크 활성 패턴
- **EEG**: 알파/세타 밴드 파워 및 안정성
- **DTI**: 백질 연결성 (구조적 상한 추정)

### 3.5.2 AI에서

- **모드 분석**: 가중치 행렬의 SVD 스펙트럼
- **활성 패턴**: 추론 중 레이어별 활성화 분포
- **안정성**: 동일 입력에 대한 출력 분산

## 3.6 한계

### 3.6.1 측정 불가능한 것

- 순간적 창의성
- 직관적 도약
- 의도/목적

### 3.6.2 측정 가능한 것

- 지능의 **상한** (구조적 용량)
- 지능의 **현재 상태** (모드 에너지 분포)
- 지능의 **안정성** (유지 시간)

> **결론**: 이 방정식은 "얼마나 똑똑한가"가 아니라 "지능이 작동할 수 있는 조건이 얼마나 갖춰져 있는가"를 측정한다.
