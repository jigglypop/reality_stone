# 5. 접힘 원리 (Folding Principle)

## 5.1 핵심 정리

### 정리 5.1 (RS-Folding Principle)

리만 다양체 $(\mathcal{M}, g)$ 위의 확산 기반 정보 밀도 $\varrho$에 대해:

1. **구조적 접힘은 $\nabla \varrho$에 수직**
2. **접힘 경계는 $\Delta_g$ 고유함수의 노드 집합**
3. **해당 접힘은 정보 거리 왜곡을 최소화한다**

### 증명 스케치

**(1) 등위면과 그라디언트의 직교성**

등위면(level set) $\{u(x) = c\}$의 접공간은 항상 그라디언트에 수직:

$$T_x(\{u = c\}) \perp \nabla u(x)$$

이는 미분기하학의 기본 정리이다.

**(2) 노드 집합이 최소 분할 경계**

Courant 노드 도메인 정리에 의해, $k$번째 고유함수 $\phi_k$는 최대 $k$개의 노드 도메인을 갖는다. 따라서 노드 집합 $\{\phi_k = 0\}$은 다양체를 최소 개수의 영역으로 분할하는 경계이다.

**(3) 스펙트럼 투영의 불연속성**

저차원 임베딩(spectral projection)은 노드 집합에서만 불연속이 발생한다. 따라서 접힘(folding)은 노드 집합에서 발생하며 이는 최적이다. $\square$

## 5.2 뇌의 주름과 LBO

### 5.2.1 피질 표면 모델

대뇌피질은 **2차원 시트가 3차원 공간에 주름져 있는 곡면**이다.

- 이랑(Gyrus): 볼록한 부분
- 고랑(Sulcus): 오목한 부분 (주름)

### 5.2.2 주름 형성 메커니즘

1. **확산 방정식**: 정보(또는 생체 물질)가 표면을 따라 확산
2. **밀도 임계점**: 특정 구역에서 밀도가 임계치 초과
3. **표면적 증가**: 밀도를 낮추기 위해 공간을 접음
4. **방향 결정**: 확산 속도가 가장 빠른 방향의 직각으로 접힘

### 5.2.3 수학적 대응

| 뇌 현상 | 수학 대응 |
|--------|----------|
| 피질 표면 | 리만 다양체 $(\mathcal{M}, g)$ |
| 주름 위치 | 노드 집합 $\{\phi_k = 0\}$ |
| 주름 방향 | $\nabla \phi_k$에 수직 |
| 이랑/고랑 깊이 | 국소 곡률 |

## 5.3 압축 알고리즘에의 적용

### 5.3.1 데이터 다양체의 접힘

고차원 데이터 공간(LLM 파라미터, 임베딩 등)을 효율적으로 압축하려면:

1. **정보 밀도가 높은 곳**을 중심으로 공간을 접어야 함
2. **어디서 접을 것인가**: 정보량 변화(그라디언트)가 가장 급격한 곳
3. **결과**: 부피는 줄어들지만 정보 표면적은 보존

### 5.3.2 최적 접힘 경계

$$\text{Optimal folding boundary} = \bigcup_{k \geq k_0} \{\phi_k = 0\}$$

여기서 $k_0$는 보존할 저주파 모드의 수이다.

### 5.3.3 접힘 방향

$$\text{Fold along } N_k, \quad \text{Project along } \nabla \phi_k$$

- $N_k = \{\phi_k = 0\}$: 노드 집합
- $\nabla \phi_k$: 그라디언트 방향

## 5.4 구현 가이드

### 5.4.1 알고리즘 개요

```
1. 데이터 다양체의 그래프 라플라시안 L 계산
2. L의 고유분해: L = Phi * Lambda * Phi^T
3. 저주파 모드 (k <= k_0) 보존
4. 고주파 모드 (k > k_0)의 노드 집합에서 접힘
5. 접힌 공간에서 재구성
```

## 5.5 왜 SVD보다 이것이 자연스러운가

### 5.5.1 SVD의 한계

- 유클리드 거리 기반 (데이터 기하 무시)
- 선형 분해 (비선형 다양체에 부적합)
- 균일 가중치 (중요도 차별 없음)

### 5.5.2 LBO 기반 접힘의 장점

- **기하 반영**: 메트릭 $g$가 데이터 구조를 인코딩
- **비선형 지원**: 다양체 위의 확산으로 비선형 관계 포착
- **자연스러운 경계**: 노드 집합이 의미론적 경계와 일치

> **결론**: LBO 기반 접힘은 "뇌 주름 같은 압축"을 가능하게 한다. 물리적 용량은 줄어들지만 정보가 닿는 표면적은 보존된다.
