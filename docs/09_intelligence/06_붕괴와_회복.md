# 6. 붕괴와 회복

## 6.1 지능 상실의 정의

### 정의 6.1 (스펙트럼 상전이)

**지능 상실**은 저주파 전역 모드를 유지하던 동역학이 붕괴되어, 고주파 잡음이 스펙트럼을 점유하는 상태로 전이되는 것이다.

$$\text{정상}: \quad a_1, a_2 \text{ 안정} + \sum_{k \gg 1} a_k \text{ 제어됨}$$

$$\text{붕괴}: \quad \sum_{k \gg 1} a_k^2 \uparrow\uparrow \quad \Rightarrow \quad a_1, a_2 \text{ 붕괴}$$

> **핵심**: 구조($\phi_k$)는 그대로인데 계수 분포($a_k$)만 바뀜

## 6.2 붕괴 유형 분류

### 6.2.1 Type I: 노화 (Entropy-driven)

**메커니즘**:
- 고주파 잡음 증가 (noise floor $\uparrow$)
- 저주파 유지 비용 증가
- 점진적 성능 저하

**수식**:
$$\text{noise floor} \uparrow \quad \Rightarrow \quad a_1 \text{ 유지 시간} \downarrow$$

**특성**:
- 느려지지만 완전 붕괴는 아님
- 회복 가능성: 제한적

### 6.2.2 Type II: 번아웃 (Overuse Collapse)

**메커니즘**:
- 임계 운용을 **너무 오래 지속**
- 에너지 고갈
- 저주파 모드가 먼저 꺼짐

**수식**:
$$E_{\text{low}} \downarrow \quad (\text{에너지 소진})$$

**특성**:
- 천재들이 가장 취약
- 회복 가능성: 높음 (휴식으로)

### 6.2.3 Type III: 정서/스트레스 붕괴 (Interference)

**메커니즘**:
- 외부 자극 $\rightarrow$ 고주파 지속 주입
- 모드 간 간섭 증가
- 전역 통합 실패

**수식**:
$$\sum_{k \gg 1} E_k \uparrow \quad \Rightarrow \quad \text{effective intelligence} \downarrow$$

**특성**:
- 구조와 무관
- 회복 가능성: 높음 (환경 변화로)

### 6.2.4 Type IV: 병리적 붕괴 (Structural Damage)

**메커니즘**:
- $\Delta_g$ 자체 손상
- 고유함수 $\phi_k$ 변형
- 비가역적

**특성**:
- 이 프레임워크의 관심 대상 아님
- 회복 가능성: 없음

## 6.3 핵심 오해 수정

### 6.3.1 잘못된 이해

> "지능을 잃었다"

### 6.3.2 올바른 이해

> "저주파 모드를 켜기 어려운 상태가 되었다"

이것이 다음 현상을 설명한다:
- 평소엔 똑똑 $\rightarrow$ 피곤하면 멍함
- 스트레스 받으면 판단력 붕괴
- 휴식 후 회복

## 6.4 회복 메커니즘

### 6.4.1 스펙트럼 냉각 (Spectral Cooling)

**원리**: 고주파 에너지를 감소시켜 저주파 모드가 다시 지배하게 함

**방법**:
- 멍 때리기 = 저주파만 남김
- 산책/단순 반복 = 고주파 감쇠
- 수면 = 스펙트럼 리셋

**수식**:
$$\frac{d}{dt} \sum_{k > k_0} a_k^2 < 0 \quad (\text{냉각})$$

### 6.4.2 AI에서의 대응

| 인간 회복 | AI 대응 |
|---------|---------|
| 휴식 | 재가열 (re-warming) |
| 수면 | 체크포인트 복원 |
| 환경 변화 | 데이터 분포 조정 |
| 치료 | 스펙트럼 재균형 |

## 6.5 회복 가능성 판정

### 표 6.1: 유형별 회복 가능성

| 유형 | 회복 가능? | 방법 | 시간 |
|-----|----------|------|------|
| Type I (노화) | 부분적 | 생활 습관 | 장기 |
| Type II (번아웃) | 예 | 휴식 | 단기~중기 |
| Type III (스트레스) | 예 | 환경/정서 | 단기 |
| Type IV (병리) | 아니오 | - | - |

## 6.6 AI 시스템에의 적용

### 6.6.1 과압축 붕괴

**현상**: 압축률을 높이면 어느 시점에서 성능이 급락

**원인**: 저주파 모드까지 손상

**해결**: 저주파 보존 제약 추가

**현상**: 훈련 중 손실이 발산

**원인**: 고주파 에너지 폭주

**해결**: 스펙트럼 정규화
