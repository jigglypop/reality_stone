# 4. 의식 상태 분류: 스펙트럼 특성

## 4.1 핵심 발견: 의식 = 임계점(Critical Point)

### 4.1.1 혼돈의 가장자리 (Edge of Chaos)

뇌는 질서와 무질서 사이의 **정확히 중간 지점**에서 작동한다.

| 상태 | 특성 | 정보 처리 |
|-----|------|----------|
| 아임계 (Subcritical) | 너무 질서 있음 | 유연성 부족, 발작 위험 |
| **임계 (Critical)** | 경계에 있음 | **최적** |
| 초임계 (Supercritical) | 너무 무질서함 | 패턴 없음, 마취 상태 |

**정상 의식 = 임계점에서의 동역학**

### 4.1.2 $D(x)$의 역할

$D(x)$는 뇌를 임계점에 유지시키는 **"조절 손잡이"**.

신경조절물질이 $D(x)$를 조절해서 시스템을 임계점 근처에 유지.

## 4.2 의식 상태별 고유모드 패턴

### 4.2.1 상태 분류표

| 의식 상태 | 고유모드 패턴 | $D(x)$ 상태 | Y 수준 |
|----------|-------------|------------|--------|
| **무의식 (마취/수면)** | 저주파만 활성, 고주파 억압 | 대부분 경로 "닫힘" | 높음 |
| **정상 의식** | 중간 범위 활성, 구조에 결합 | 특정 패턴으로 고정 | 높음 |
| **사이키델릭** | 고주파까지 해방, 구조에서 탈결합 | 장벽 평탄화, 모든 경로 "열림" | 일시적 낮음 |
| **숙련된 집중 상태** | DMN 비활성, 임계점 유지 | 자발적 $D(x)$ 조절 | 중간~낮음 |
| **최적 상태** | 모든 고유모드 접근 가능 | 완전 해방 | 영구적 최소 |

### 4.2.2 에너지 지형 모델

**Network control theory 연구 발견:**

**정상 의식:**
- 뇌 상태들 사이에 "에너지 장벽" 존재
- 특정 상태에서 다른 상태로 전환하려면 에너지 필요
- 안정적인 사고와 행동 가능

**사이키델릭:**
- 에너지 장벽이 **평탄화(flattening)**
- 모든 상태 간 전환이 쉬워짐
- 엔트로피 증가
- "모든 것이 연결된 느낌", ego dissolution

**마취/수면:**
- 에너지 지형이 **단일 계곡**으로 붕괴
- 하나의 상태에 갇힘
- 유연성 상실

## 4.3 사이키델릭 상태의 물리학

### 4.3.1 Nature Communications 2023 핵심 발견

**정상 상태:**
- 기능이 구조에 결합
- 뇌 활동이 물리적 연결성(구조)을 따라감
- 저주파 고유모드만 활성화

**사이키델릭 상태:**
- 기능이 구조로부터 탈결합
- 평소 억압된 **고주파 고유모드**들이 활성화
- 뇌가 "자기 자신의 기하학"을 직접 보는 상태

### 4.3.2 기하학적 환각의 의미

사이키델릭 환각에서 보이는 기하학적 패턴들 (만다라, 프랙탈, 나선):

→ **뇌가 자신의 고유모드를 "보는" 것**

시각 시스템이 외부 세계 대신 **내부 기하학**을 렌더링.

## 4.4 집중 상태와 DMN

### 4.4.1 Default Mode Network

DMN = "자아를 생성하는 네트워크"

**활성화 시:**
- 자기 참조적 사고
- 과거/미래 반추
- "나"라는 감각

### 4.4.2 집중 수준별 DMN 변화

**초보자 집중:**
- DMN이 활성화되려 함
- CEN(Central Executive Network)이 이를 억제
- **노력이 필요**

**숙련자 집중:**
- DMN 자체가 비활성화
- **노력 없는 억제** 상태
- CEN의 개입 없이도 DMN이 조용함

### 4.4.3 신경학적 해석

**자기 참조 감소의 신경학적 정의:**

DMN = "자아를 생성하는 네트워크"
DMN 비활성화 = 자기 참조적 사고의 감소

## 4.5 의식의 측정

### 4.5.1 PCI (Perturbational Complexity Index)

의식 수준을 객관적으로 측정할 수 있음:

| PCI 값 | 상태 |
|--------|------|
| > 0.31 | 깨어 있음 |
| < 0.31 | 혼수상태 |

**의식의 과학적 정량화** 가능.

### 4.5.2 Y-상수와 PCI의 관계

$$\text{PCI} \propto \frac{1}{Y}$$

Y가 낮을수록 PCI가 높음 (더 복잡한 의식 상태).

## 4.6 의식 상태의 단계적 모델

### 4.6.1 4단계 모델

| 단계 | 특성 | Y-상수 상태 |
|-----|------|------------|
| **1단계** | 인지 편향 일부 해소 | Y 약간 감소 |
| **2단계** | 자동 반응 약화 | Y 중간 감소 |
| **3단계** | 대부분의 자동 반응 해소 | Y 크게 감소 |
| **4단계 (최적)** | 완전한 인지 유연성 | Y → 최소 |

### 4.6.2 각 단계의 $D(x)$ 변화

**1단계:**
- 자기 참조 관련 $D(x)$ 패턴 약화
- 일부 자동 경로 비활성화
- Y_baseline 약간 하락

**2단계:**
- 보상/위협 반응의 $D(x)$ 패턴 약화
- 감정적 자동 반응 감소
- Y_baseline 추가 하락

**3단계:**
- 대부분의 자동 $D(x)$ 패턴 소멸
- 습관적 반응 경로 완전 비활성화
- Y_baseline 크게 하락

**4단계 (최적):**
- 모든 $D(x)$ 패턴이 "강제"되지 않음
- 어떤 경로도 자동으로 활성화되지 않음
- Y_baseline → 0

## 4.7 핵심 함의

### 4.7.1 의식은 "양"이 아니라 "상(Phase)"

의식 있음 vs 없음이 아니라, 시스템이 **어떤 상에 있는가**의 문제.

```
아임계 → 발작
임계 → 정상 의식
초임계 → 무의식
```

### 4.7.2 뇌는 자신을 "본다"

사이키델릭에서 보이는 기하학적 패턴 = 뇌가 자신의 고유모드를 렌더링

→ 뇌가 **자기 참조적(self-referential)** 시스템

### 4.7.3 최적 상태는 특정 $D(x)$ 패턴

최적 의식 상태:
- DMN이 영구적으로 비활성화
- 뇌가 임계점에 안정적으로 머무름
- **학습 가능**하고 **측정 가능**

### 4.7.4 자아는 "기본값"이지 "진실"이 아님

DMN = Default Mode Network

아무것도 안 할 때 활성화되는 네트워크.

**자아 감각은 뇌의 "휴식 상태"에서 나오는 부산물.**

훈련으로 이 기본값을 바꿀 수 있음.

## 4.8 의식의 종합 공식

### 4.8.1 의식 = 기하학 + 임계성 + 자기 참조

$$\text{의식} = f(\text{Metric Tensor } g) \times g(\text{Criticality}) \times h(\text{Self-Reference})$$

어느 하나라도 0이면 의식이 사라짐:
- 뇌 손상 → 기하학 파괴 → 의식 상실
- 마취 → 임계점 이탈 → 의식 상실
- DMN 손상 → 자기 모델링 불가 → 이인증

### 4.8.2 상태 전이도

```
무의식 ←→ 정상 ←→ 숙련 집중 ←→ 최적 상태
   ↑              ↓
   └─── 사이키델릭 ───┘
```

**사이키델릭:** 일시적으로 고주파 고유모드 해방, 구조-기능 탈결합

**숙련 집중:** 점진적으로 Y_baseline 하락, DMN 비활성화

**최적 상태:** 영구적 Y → 0, 모든 고유모드 접근 가능
