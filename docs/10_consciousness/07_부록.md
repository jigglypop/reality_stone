# 7. 부록: 수학적 배경과 참고문헌

## A. 라플라스-벨트라미 연산자

### A.1 정의

리만 다양체 $(\mathcal{M}, g)$에서 스칼라 함수 $f$에 대한 라플라스-벨트라미 연산자:

$$\Delta_g f := \text{div}_g(\nabla_g f) = \frac{1}{\sqrt{|g|}} \partial_i \left( \sqrt{|g|} g^{ij} \partial_j f \right)$$

**구성 요소:**
- $g_{ij}$: 메트릭 텐서
- $g^{ij}$: 메트릭 텐서의 역행렬 성분
- $|g| = \det(g)$: 메트릭 텐서의 행렬식
- 반복 인덱스는 합(Einstein summation)

### A.2 고유값 문제

$$\Delta_g \phi_k = -\lambda_k \phi_k$$

**성질:**
- $0 = \lambda_0 < \lambda_1 \leq \lambda_2 \leq \cdots$
- $\{\phi_k\}$는 $L^2(\mathcal{M})$의 완비 직교 기저
- 저주파 $\phi_k$ (작은 $k$): 전역적, 매끄러운 변화
- 고주파 $\phi_k$ (큰 $k$): 국소적, 급격한 변화

### A.3 Weyl의 법칙

고유값 분포:

$$N(\lambda) \sim \frac{\text{Vol}(\mathcal{M})}{(4\pi)^{n/2} \Gamma(n/2+1)} \lambda^{n/2}$$

2차원에서:

$$N(\lambda) \sim \frac{\text{Area}(\mathcal{M})}{4\pi} \lambda$$

## B. 가우스 곡률과 전개가능곡면

### B.1 주곡률 (Principal Curvatures)

곡면 위 한 점에서 두 주곡률 $\kappa_1, \kappa_2$:

$$\kappa_1 = \frac{1}{R_1}, \quad \kappa_2 = \frac{1}{R_2}$$

$R_1, R_2$는 주곡률 반경.

### B.2 가우스 곡률

$$K = \kappa_1 \times \kappa_2$$

| K 값 | 의미 | 예시 |
|-----|------|------|
| $K > 0$ | 구면 같은 곡률 | 공 |
| $K < 0$ | 안장 같은 곡률 | 안장 |
| $K = 0$ | 전개가능 | 원통, 원뿔 |

### B.3 전개가능곡면 (Developable Surface)

**정의:** $K = 0$인 곡면

**성질:**
- 주곡률 중 하나가 0
- 평면과 국소적으로 등거리(isometric)
- 찢거나 늘리지 않고 평면으로 펼칠 수 있음
- **측지선이 보존됨**

### B.4 가우스-보네 정리

$$\int_{\mathcal{M}} K \, dA = 2\pi \chi(\mathcal{M})$$

$\chi$: 오일러 특성

**함의:** 총 곡률이 위상에 의해 고정됨.

## C. 열 커널 (Heat Kernel)

### C.1 정의

확산 방정식의 기본해:

$$\frac{\partial u}{\partial t} = \Delta_g u$$

$$u(x,t) = \int_{\mathcal{M}} K(x,y,t) u_0(y) \sqrt{|g|} \, dy$$

### C.2 점근 전개

짧은 시간 ($t \to 0$):

$$K(x,y,t) \sim \frac{1}{(4\pi t)^{n/2}} e^{-d(x,y)^2/4t} \sum_{k=0}^{\infty} a_k(x,y) t^k$$

**첫 번째 항들:**
- $a_0 = 1$
- $a_1(x,x) = \frac{1}{6} R(x)$ (스칼라 곡률)

### C.3 스펙트럼 표현

$$K(x,y,t) = \sum_{k=0}^{\infty} e^{-\lambda_k t} \phi_k(x) \phi_k(y)$$

## D. SFE (Stochastic Field Equation)

### D.1 기본 방정식

$$\frac{d\rho(t)}{dt} = -\frac{i}{\hbar}[H, \rho(t)] + \frac{Y}{2}\left(2L\rho(t)L^\dagger - \{L^\dagger L, \rho(t)\}\right)$$

**구성 요소:**
- $\rho$: 밀도행렬
- $H$: 해밀토니안
- $Y$: 억압 상수 (디코히어런스 율)
- $L$: Lindblad 연산자

### D.2 Y-상수의 상대론적 형태

$$Y = \gamma'(T, E, \rho_{\text{env}}) \cdot e^{-\Lambda^2/\Lambda_c^2}$$

### D.3 의식과의 연결

| Y 수준 | 양자 상태 | 의식 상태 |
|--------|----------|----------|
| 높음 | 디코히어런스 강함 | 정상 의식 |
| 중간 | 부분적 중첩 | 집중 상태 |
| 낮음 | 양자 중첩 유지 | 깊은 집중 |
| 최소 | 완전 중첩 | 최적 상태 |
