## 🔍 문제 분석

### 주제 분류 실패 원인

1. **학습 데이터 부족**
   - 100개 샘플만 사용
   - 주제 레이블 없음 (pseudo-label 사용)
   - 3 에포크만 학습

2. **Loss 함수 문제**
   ```python
   # 현재: uniform pseudo-label
   topic_target = torch.zeros_like(P_topic)
   topic_target[:, :, 7] = 1.0  # 모두 "general"
   ```
   → 실제 주제 레이블 필요

3. **데이터 불균형**
   - 모든 샘플이 비슷한 도메인 (위키피디아)
   - 의료 데이터 부족

### NaN 문제 원인

```python
# SentenceTopicHead forward에서
P_topic = F.softmax(logits, dim=-1)
```

- Logits이 초기화 상태 (학습 안됨)
- Softmax 결과가 NaN
- 학습이 제대로 안됨 (loss=0.0000)
