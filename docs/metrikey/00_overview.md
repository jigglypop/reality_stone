# 00. Overview — MetriKey

- 문제: 권한/조직 계층을 반영하면서 단일 인덱스로 고성능 검색/추론 수행
- 해법 요지:
  - 메트릭=키: 권한 키로 SPD 메트릭 G_k 생성, d_k(x,y)로 정책을 거리화
  - 순서보존 합성: 전 리만 레이어를 합성행렬 T_total로 묶어 추론 경로 단일화(무손실 시 압축률≈레이어 수)
  - 하이브리드 검색: 쿼리 전처리(L_k q) + 표준 ANN, 상위 M만 지오데식/마할라노비스 재랭크

## 기대효과
- 포스트 필터 없이 품질·지연 유지(정책=거리)
- 단일 인덱스 운영으로 스토리지 중복·운영 복잡도 감소
- 전 레이어 합성으로 추론 지연 감소
- 키 없인 공간 복원 불가(보안 효과, 암호는 아님)

## 적용 범위
- Reality Stone(리만 연산/압축)과 결합한 RAG/검색/추론 시스템 전반
