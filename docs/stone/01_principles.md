# 01. Principles — Core Ideas

- 메트릭=키
  - 키→SPD 메트릭 G_k 생성
  - Mahalanobis d_k(x,y) 또는 g-직교 전처리(L_k x)로 정책=거리화
- 순서보존 합성
  - 레이어별 리만 변환을 합성행렬 T_total로 묶어 추론 1회화
  - 무손실 시 이론적 압축률≈레이어 수 L
- 하이브리드 검색
  - 쿼리 1회 전처리 + 표준 ANN(HNSW/IVF/OPQ)
  - 상위 M 재랭크(지오데식/마할라노비스)
- 정합성 보장
  - g-직교(R^T g R = g), 블록-직교 설계(전역/사일로)로 랭킹 불변
- 교환성/결합성 설계
  - 메트릭/곡률 결합은 선형·대칭을 우선(교환성/결합성 보장)
  - 불가피한 비대칭/비선형은 순서 고정으로 재현성 확보
